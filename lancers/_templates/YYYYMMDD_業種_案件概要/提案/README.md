# 提案（スキルの出力先）

このフォルダはスキルが書き込む。最初は空でよい。

| ファイル | いつできる | 中身 |
|---|---|---|
| `design.md` | Phase A | 要件整理・勝ち筋の仮説・置いた仮定 |
| `tone-spec.md` | Phase A-2 | 参考サイトのトーン仕様（固定フォーマット） |
| `design-prompt.md` | Phase A-4 | Claude Design に投げるプロンプト（2〜3案分） |
| `質問リスト.md` | Phase A-3 | 依頼者への質問／ユーザーへの質問を分けて記載 |
| `素材指示.md` | Phase C | 必要な写真の仕様。**モック画面内には書かない** |
| `提案文.md` | Phase E | 提出する提案文 |
| `見積.md` | Phase E | 金額と「今回の想定範囲」 |
| `振り返り.md` | 結果が出たあと | 採用／不採用の理由。アーカイブ前に書く |

モック本体（Claude Design の Handoff bundle）もここに置く。

## 提出前チェック

- [ ] 画面内に説明書き・ラベル・注記・仮テキストが残っていないか
- [ ] コピーが本番想定の文言になっているか（「ここにキャッチコピー」等がない）
- [ ] 見積に「今回の想定範囲」が1行入っているか
- [ ] **モックURLを公開に変えたか**（初期状態は非公開。貼っても依頼者は開けない）
- [ ] 申し送りリストを出したか（Figma化する場合）
