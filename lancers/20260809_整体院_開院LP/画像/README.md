# 画像

| フォルダ | 入れるもの |
|---|---|
| `支給素材/` | 依頼者から受け取ったもの。**加工も上書きもしない** |
| `自前素材/` | 自分で用意・加工したもの。ストック写真、トリミング済み画像など |

支給素材を直接加工すると、差し替え依頼が来たときに元に戻せなくなる。
加工したものは必ず `自前素材/` に別名で置く。

## ファイル名

用途が分かる名前にする。モックのレイヤー名・HTMLコメントと対応させると
Figma化のときに迷わない。

```
hero-main.jpg
about-portrait.jpg
service-01.jpg
logo.svg
```

## 素材が未支給の段階

グレーの矩形やアイコン入りプレースホルダーは**使わない**。
トーンの合った仮写真を入れるか、画像なしで成立する構成に切り替える。
仮画像を使ったことは画面に書かず、チャットと `提案/素材指示.md` で伝える。
