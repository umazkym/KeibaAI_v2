# 採用（受注できた案件）

受注できた案件フォルダをそのまま移してくる。

```bash
mv ~/lancers/20260812_歯科_リニューアル ~/lancers/_archive/採用/
```

## なぜ残すのか

ここは**依頼者が実際に発注を決めた基準**が入った一次情報。
スキルは Phase A-1 の冒頭でこのフォルダを読み、勝ちパターンの材料にする。

読むときは見た目を真似せず、3層に分解して扱う。

| 層 | 例 | 扱い |
|---|---|---|
| 機能 | 連絡手段の置き方、実績の見せ方 | 踏襲する |
| トーン | 親しみやすい／格式高い | 外すなら明示する |
| 表層 | 色・書体・レイアウト | 別解にしてよい |

## 移す前に1つだけ書く

案件フォルダの `提案/振り返り.md` に、**なぜ選ばれたか**を残す。
依頼者がコメントをくれていればその原文を貼る。憶測なら憶測と書く。

```markdown
# 振り返り

- 結果：採用
- 提案者数：
- 決め手（依頼者コメントがあれば原文）：
- 自分の見立て：
- 次に活かす点：
```

これがないと、フォルダだけ増えて材料にならない。
