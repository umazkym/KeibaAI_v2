# 不採用（落ちた案件）

落ちた案件フォルダを移してくる。捨てない。

```bash
mv ~/lancers/20260812_歯科_リニューアル ~/lancers/_archive/不採用/
```

## なぜ残すのか

落ちた理由は採用理由より情報量が多いことがある。特に次の2つは記録する価値が高い。

- **採用された他者の案が見えた場合**：何が上だったのかを3層に分解する
- **提案すらされなかった場合**：応募文で落ちている。デザインの問題ではない

後者は見落としやすい。デザインを磨いても解決しないので、
応募文・単価・返信速度のどこで落ちたかを切り分ける。

## 移す前に1つだけ書く

`提案/振り返り.md` に書く。

```markdown
# 振り返り

- 結果：不採用
- 提案者数：
- 採用された案（見えれば URL やスクショ）：
- 落ちた場所の見立て：（応募文／単価／デザイン／納期／不明）
- 次に変える点：
```

「不明」と書くのは構わない。憶測を確定のように書くほうが害になる。
