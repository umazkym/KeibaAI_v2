# KeibaAI_v2 特徴量拡張 総合分析レポート

## エグゼクティブサマリー

現行V14の分析に基づき、**38個の新規特徴量候補**を特定・評価しました。
そのうち**12個が高インパクト**と評価され、特に以下の4カテゴリが市場の非効率性を捕捉する上で有望です：

1. **展開予測系** - ペース予測は市場最大の盲点
2. **市場バイアス系** - 直近成績への過剰反応を検出
3. **血統深層系** - 母父の影響を独立して捕捉
4. **高度統計系** - Eloレーティングによる実力評価

## 2. 高優先度 新規特徴量（優先度A）

これらは既存データから即座に実装可能であり、高いROI改善効果が見込まれます。

### 2.1 Eloレーティング（elo_rating）
**概念**: チェスのEloレーティングを競馬に適用し、相対的な強さを数値化。
- **計算**: 初期値1500、K=32。先着した相手のレートが高いほど大きく上昇。
- **価値**: 「弱い馬に大勝」より「強い馬に惜敗」を高く評価できる。
- **実装**: `races.parquet` の同一レース内での総当たり対戦として計算。

### 2.2 直近成績バイアス指標（recency_bias_indicator）
**概念**: 市場が直近成績に過剰反応している乖離を検出。
- **計算**: (期待着順_from_odds) - (期待着順_from_past_5_avg)
- **価値**: 正の値が大きい＝市場が過小評価（実力はあるが直近で人気落ち）。
- **実装**: `shutuba.parquet` の `morning_odds` と過去成績を使用。

### 2.3 全コーナー馬身差（gap_c1_avg, gap_c2_avg, gap_c3_avg）
**概念**: スタート直後からの位置取りと余力の推移を可視化。
- **現状**: C4のギャップのみ使用。
- **拡張**: `corner_positions.parquet` からC1, C2, C3の先頭からの馬身差を集計。
- **価値**: 「行き脚がつかない」のか「あえて控えている」のかを区別可能。

### 2.4 追い込み力指標（gap_reduction_c1_c4, gap_reduction_c3_c4）
**概念**: レース後半での「脚の使い所」を定量化。
- **計算**: gap_c1_avg - gap_c4_avg（全体的進出）、gap_c3_avg - gap_c4_avg（直線瞬発）。
- **価値**: 3-4コーナーでのまくり能力や、直線の瞬発力を特定。

## 3. 中優先度 新規特徴量（優先度B）

### 3.1 母父勝率（broodmare_sire_win_rate）
**概念**: 母の父（BMS）の遺伝的影響（スタミナ、気性）を評価。
- **実装**: `pedigrees.parquet` で `generation=2` かつ母方の祖先を取得。
- **価値**: 長距離や特殊な馬場条件での隠れた適性を発見。

### 3.2 予測ペース（expected_front_runners）
**概念**: メンバー構成からレース展開（H/M/S）を予測。
- **計算**: 過去の逃げ率（`horse_front_runner_rate`）が高い馬の数をカウント。
- **価値**: 逃げ馬多数＝ハイペース＝差し馬有利、という展開のアヤを予測。

### 3.3 コースペース傾向（course_pace_tendency）
**概念**: コースごとの「流れやすさ」を統計化。
- **実装**: `race_details.parquet` の `first_half`, `second_half` を使用し、コース×距離ごとの平均ペースバランスを計算。

### 3.4 詳細脚質分類（差し_rate, 追込_rate）
**概念**: 脚質をより細分化して評価。
- **実装**: C1通過順位に基づき、逃げ/先行/差し/追込の4カテゴリでの経験率を計算。

## 4. 要注意 新規特徴量（優先度C）

### 4.1 オッズ変動（odds_movement）⚠️
**概念**: 朝オッズから最終オッズへの資金流入検知。
- **注意**: オッズは学習時には「未来情報」になりうるため、厳密に朝オッズのみを使用するか、推論時のみのメタ特徴量として扱う必要がある。V15では一旦除外推奨。

### 4.2 標準化スピード指数（speed_figure_standardized）
**概念**: 走破タイムの偏差値化。
- **課題**: 馬場差補正が複雑であり、誤った補正はノイズになるリスクがある。

## 6. 過学習防止チェックリスト

全ての新規特徴量に対して以下を厳守します：
- ✅ **Point-in-Time**: 必ず `cumsum().shift(1)` を使用し、当該レースの情報を含めない。
- ✅ **最小サンプル数**: 統計的有意性のないデータ（初出走馬のEloなど）は欠損値またはデフォルト値とする。
- ✅ **リーク確認**: `race_details` のタイム情報は予測対象レースでは絶対に使用しない（過去統計としてのみ使用）。
