# ROI低下に関する詳細分析レポート (v2.3)

**作成日**: 2025-11-27
**対象バージョン**: v2.3 (Updated)
**分析テーマ**: モデル精度向上とROI低下の因果関係について

## 1. 現象の確認

最新のモデル更新（v2.3）において、以下の現象が確認されました。

*   **精度指標の向上**:
    *   AUC: 0.7771 -> **0.7787** (向上)
    *   Accuracy (Top1): 27.29% -> **27.36%** (向上)
    *   LogLoss: **0.2256** (良好)
*   **収益指標の低下**:
    *   ROI (Top1): 80.66% -> **77.47%** (約3.2ポイント低下)

一見矛盾するように見えますが、これは予測モデルにおいて**「精度(Correctness)」と「収益性(Profitability)」が必ずしも相関しない**という典型的な現象です。

## 2. 原因推論: "大衆化"の罠 (The Consensus Trap)

今回のROI低下の主たる原因は、**「モデルが『誰もが知っている強さ』を学習しすぎてしまったこと」**にあると強く推測されます。

### A. 新機能の特性分析
今回追加・強化された特徴量は、いずれも**「一般の競馬ファンも重視する指標」**です。

1.  **騎手・調教師の近走成績 (Recent Form)**
    *   *内容*: 「ルメール騎手は最近調子が良い」「矢作厩舎は今月勝ちまくっている」といった情報。
    *   *市場への影響*: これらの情報は競馬新聞やネットで誰でも確認できるため、**オッズに即座に反映（過剰人気）**されます。
    *   *モデルへの影響*: モデルはこの「わかりやすい強さ」を検知し、人気馬（低オッズ馬）をより自信を持って推論するようになります。

2.  **騎手×競馬場 相性 (Jockey-Venue Affinity)**
    *   *内容*: 「東京のルメール」「中山の戸崎」といった定石。
    *   *市場への影響*: これも周知の事実であり、該当する条件では過剰に馬券が売れます。
    *   *モデルへの影響*: 的中率は上がりますが、配当妙味のない馬ばかりを推奨するようになります。

3.  **生産者・産地情報 (Breeder/Area)**
    *   *内容*: 「ノーザンファーム生産馬」など。
    *   *市場への影響*: 現代競馬において最も強力なブランドであり、常に過剰人気になります。

### B. メカニズムの解説
LightGBMなどの機械学習モデルは、デフォルトで「正解率（LogLossやAUC）」を最大化しようとします。
モデルにとって、**「オッズ1.1倍の圧倒的人気馬」を当てること**は、正解率を稼ぐための最も効率的な戦略です。

*   **以前のモデル**: 騎手や生産者の情報が少なかったため、純粋な「過去の着順」や「バイアス（枠順・展開）」など、**オッズに織り込まれにくい渋い要素**で判断していました。その結果、人気薄の好走を見抜く余地がありました。
*   **現在のモデル**: 騎手や生産者の強力なシグナルを手に入れたため、**「強い馬（＝人気馬）」を素直に評価する**ようになりました。結果、的中率は上がりましたが、配当が安い馬ばかりを拾うようになり、トータルの回収率が下がりました。

## 3. 結論: モデルは「賢く」なったが「儲からなく」なった

現在のモデルは、競馬予想AIとしては**「正しく進化」**しています。馬の能力をより正確に評価できています。
しかし、馬券投資AIとしては**「大衆迎合」**してしまっています。

### 「精度向上 = ROI向上」ではない
*   **精度向上**: 本命サイド（低配当）の的中精度が上がった。
*   **ROI低下**: 穴サイド（高配当）の検知力が相対的に下がった、あるいは本命サイドの購入比率が増えて「トリガミ（的中してもマイナス）」が増えた。

## 4. 今後の対策方針 (Next Steps)

コード修正は行いませんが、次期バージョンに向けた指針を提示します。

### A. 特徴量の選別 (Feature Selection)
「大衆が注目しすぎる指標」の影響力を下げる必要があります。
*   **案**: `jockey_win_rate` や `breeder_win_rate` などの「人気直結型特徴量」をあえて削除するか、正則化を強める。

### B. ターゲットの変更 (Target Engineering)
「勝つこと」ではなく「儲かること」を教える必要があります。
*   **案**: 学習時の目的変数を単純な `0/1` (勝ち負け) ではなく、**`is_win * log(odds)`** のように、オッズで重み付けした値を学習させる（配当が高いレースほど重視する）。

### C. 評価指標のシフト (Metric Shift)
モデルの評価をAUCやAccuracyではなく、**「シミュレーションROI」**に完全移行する時期に来ています。
*   **σモデル・νモデルの出番**: μモデル（勝率予測）は今のまま「高精度な本命予測機」として完成させ、**「過剰人気している本命馬を消す（σモデル）」**や**「期待値の高い穴馬を拾う（νモデル）」**という役割分担を明確にすべきです。

## 5. 総括
ROIの低下は失敗ではなく、**「モデルが市場のコンセンサス（オッズ）に近づいた証拠」**です。
これ以上のμモデル単体でのROI向上は「オッズの歪み」を突くことと同義であり、それはμモデルの役割（純粋な能力評価）を超えつつあります。
今後は、この高精度なμモデルをベースに、**賭け方（Betting Strategy）の最適化**に注力すべきフェーズです。
