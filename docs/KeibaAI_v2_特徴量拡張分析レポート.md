# KeibaAI_v2 特徴量拡張 総合分析レポート

## エグゼクティブサマリー

現行V15の55特徴量を分析し、**38個の新規特徴量候補**を特定しました。
そのうち**12個が高インパクト**と評価され、特に以下の4カテゴリが市場の非効率性を捕捉する上で有望です：

1. **展開予測系** - ペース予測は市場最大の盲点
2. **市場バイアス系** - 直近成績への過剰反応を検出
3. **血統深層系** - 母父の影響を独立して捕捉
4. **高度統計系** - Eloレーティングによる実力評価

## 2. 高優先度 新規特徴量（優先度A）

### 2.1 Eloレーティング（elo_rating）
```
概念: チェスのEloレーティングを競馬に適用

利点:
- 「強い馬に僅差で負けた」と「弱い馬に大敗した」を区別
- 既存のhorse_cum_win_rateでは捉えられない「相対的実力」を評価

計算ロジック:
1. 初期レーティング = 1500
2. 各レース後、対戦相手の強さに応じてレーティング更新
3. K-factor = 32（調整可能）

リーク防止: 当該レース以前のレースのみで計算（shift(1)必須）
```

### 2.2 直近成績バイアス指標（recency_bias_indicator）
```
概念: 市場が直近成績に過剰反応していることを検出

市場心理:
- 前走大敗 → 人気急落（実力以上に過小評価）
- 前走勝利 → 人気急上昇（実力以上に過大評価）

計算ロジック:
1. 直近1走の着順と過去5走平均の乖離を計算
2. 人気から期待される着順を算出
3. 実力(過去5走平均)と市場評価(人気)の差をスコア化

正の値 = 市場が過小評価（狙い目）
負の値 = 市場が過大評価（避けるべき）

リーク防止: 過去成績と朝人気のみ使用
```

### 2.3 全コーナー馬身差（gap_c1_avg, gap_c2_avg, gap_c3_avg）
```
概念: 既存のc4_gap_avgを全4コーナーに拡張

現状の問題:
- C4のみでは「いつ追い込んだか」が不明
- 早めに仕掛ける馬 vs 直線勝負の馬を区別できない

追加特徴量:
- gap_c1_avg: 1コーナー平均馬身差
- gap_c2_avg: 2コーナー平均馬身差  
- gap_c3_avg: 3コーナー平均馬身差

corner_positions.parquetの活用で即座に実装可能
```

### 2.4 追い込み力指標（gap_reduction_c1_c4, gap_reduction_c3_c4）
```
概念: コーナー間の馬身差縮小量で追い込み力を定量化

gap_reduction_c1_c4 = gap_c1_avg - gap_c4_avg
  → 全体的な追い込み力

gap_reduction_c3_c4 = gap_c3_avg - gap_c4_avg
  → 直線での瞬発力（最終コーナーからゴールまでの加速力）

市場が見落とす理由:
- 着順だけでは「どこで追い込んだか」が不明
- 直線勝負型 vs 持久力型を区別できる
```

## 3. 中優先度 新規特徴量（優先度B）

### 3.1 母父勝率（broodmare_sire_win_rate）
```
概念: 母父（BMS = Broodmare Sire）の産駒成績

血統学的背景:
- 父の影響: スピード、瞬発力
- 母父の影響: スタミナ、気性、成長力
- 母父の影響は3歳以降・長距離で顕在化

実装:
1. pedigrees.parquetからgeneration=2の母方祖先を特定
2. その祖先を母父として持つ馬の成績を集計
3. 固定統計値として事前計算可能

市場が見落とす理由:
- 父のブランド（サンデーサイレンス系など）は注目される
- 母父は専門的すぎて一般ファンは軽視
```

### 3.2 予測ペース（expected_front_runners）
```
概念: 出走馬の脚質構成からレースペースを事前予測

計算ロジック:
1. 各出走馬の過去「逃げ率」「先行率」を集計
2. レース全体の逃げ馬数を予測
3. 逃げ馬複数 → ハイペース予測
4. 逃げ馬不在 → スローペース予測

既存との差別化:
- front_runner_competition: 逃げ馬の「競合の有無」のみ
- expected_front_runners: 「何頭の逃げ馬がいるか」を定量化

リーク防止: 出走馬の過去データのみ使用（当該レース結果は未使用）
```

### 3.3 コースペース傾向（course_pace_tendency）
```
概念: 同条件過去レースのペース傾向を統計化

例: 「中山1200mはハイペースになりやすい」
    「東京2400mはスローペースになりやすい」

計算:
- 同競馬場×同距離×同馬場状態の過去レースを抽出
- first_half / second_half の平均値を計算
- >1.0: ハイペース傾向、<1.0: スローペース傾向

race_details.parquetの活用で実装可能
```

### 3.4 詳細脚質分類（差し_rate, 追込_rate）
```
概念: 既存のfront_runner_rateを4分類に拡張

現状: 逃げ率のみ
拡張: 逃げ / 先行 / 差し / 追込 の4分類

判定基準:
- 逃げ: C1で1番手
- 先行: C1で2-4番手
- 差し: C1で5-8番手、途中で上昇
- 追込: C1で9番手以降、直線勝負

各脚質での過去成績も同時に計算
```

## 4. 要注意 新規特徴量（優先度C）

### 4.1 オッズ変動（odds_movement）⚠️
```
概念: 朝オッズ → 最終オッズの変動率

価値:
- 変動率 < 1: 支持上昇（内部情報の可能性）
- 変動率 > 1: 支持低下（悪材料の可能性）

⚠️ リークリスク:
- 最終オッズは発走直前の情報
- 学習時に使用すると「未来の情報」でリーク

対策:
- リアルタイム予測専用として分離
- 学習時は朝オッズのみ使用
- 最終オッズは推論時のみ使用
```

### 4.2 標準化スピード指数（speed_figure_standardized）
```
概念: 走破タイムを条件補正して標準化

計算:
1. 距離×馬場状態×競馬場で過去タイムの平均・標準偏差を計算
2. 当該馬のタイムをZ-score化
3. 偏差値（平均50、標準偏差10）に変換

実装難易度: 高（補正係数の妥当性検証が必要）
期待効果: 高（絶対的な「速さ」を評価できる）
```

## 6. 過学習防止チェックリスト

### ✅ 実装前に確認
- [ ] すべての累積統計にshift(1)を適用しているか
- [ ] 当該レースの情報（結果、タイム、ペース）を使用していないか
- [ ] 新特徴量の計算に最低3-5レースのサンプルを要求しているか

### ✅ 実装後に確認
- [ ] 新特徴量と既存特徴量の相関が0.8未満か
- [ ] 検証セットでの性能が改善しているか
- [ ] 異なる年・季節でのパフォーマンスが一貫しているか

### ✅ 定期モニタリング
- [ ] 特徴量重要度が0.01以上を維持しているか
- [ ] 学習/検証/テストの性能差が大きくないか
- [ ] 新規データでの性能が安定しているか

## 8. 期待される改善効果

### 定量的目標
- **ROI**: 現行比 +3-5%ポイント（市場非効率性の追加捕捉）
- **的中率**: 現行比 +1-2%ポイント（実力評価の精度向上）
- **回収率の安定性**: 月間標準偏差の低減

### 定性的改善
- 展開予測の精度向上 → ペース不適合馬を排除
- 市場バイアスの直接検出 → 過小評価馬の発見
- 血統分析の深化 → 長距離・重馬場での優位性

## 9. 結論

KeibaAI_v2の「市場の非効率性を突く」という設計思想に基づき、以下の特徴量追加を強く推奨します：

### 即座に追加すべき特徴量（優先度A）
1. **elo_rating** - 相手の強さを考慮した実力評価
2. **recency_bias_indicator** - 市場の過剰反応を直接検出
3. **gap_c1-c3_avg** - 全コーナーでの位置取り
4. **gap_reduction** - 追い込み力の定量化

### 検証後に追加すべき特徴量（優先度B）
5. **broodmare_sire_win_rate** - 母父の影響
6. **expected_front_runners** - ペース予測
7. **course_pace_tendency** - コース特性
8. **詳細脚質分類** - 4分類の脚質

これらの特徴量は、既存V15の特徴量と相補的であり、市場が見落としている情報を体系的に捕捉することで、Edge Scoreの精度向上に貢献することが期待されます。
