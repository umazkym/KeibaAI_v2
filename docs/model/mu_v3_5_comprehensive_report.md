### 6.2 推奨戦略

#### 戦略B: Insights Kelly（推奨）

2023年の分析から導出した知見に基づき、Kelly係数を調整：

| 条件 | Kelly係数ボーナス |
|------|------------------|
| 中穴ゾーン（10-50倍） | +50% |
| 5番人気 | +30% |
| 中距離（1800-2200m） | +20% |

**期待ROI**: 90~100%（保守的に見積もり）

```python
def insights_kelly_weight(row, base_fraction=0.25):
    p = row['win_prob_estimated']
    odds = row['win_odds']
    
    b = odds - 1
    kelly_full = (p * b - (1 - p)) / b
    
    if kelly_full <= 0:
        return 0.0
    
    adjustment = 1.0
    
    # 中穴ゾーンボーナス
    if 10 <= odds <= 50:
        adjustment += 0.5
    
    # 5番人気ボーナス
    if row['popularity'] == 5:
        adjustment += 0.3
    
    # 中距離ボーナス
    if 1800 <= row['distance_m'] <= 2200:
        adjustment += 0.2
    
    return min(kelly_full * base_fraction * adjustment, 0.15)
```
