# μモデル (Mu Estimator) 概要

**最新バージョン**: v2.7 (ROI Maximization)
**更新日**: 2025-11-29

## 1. モデルの目的
μモデルは、KeibaAIの中核となる**勝率予測モデル**です。
各馬がレースで1着になる確率（または複勝圏内に入る確率）を推定し、馬券購入の判断材料となるスコアを提供します。

v2.6以降、単なる「的中率」の最大化ではなく、**「期待値（ROI）」の最大化**へと戦略を転換しました。

## 4. モデルの構造

### アルゴリズム
- **LightGBM (Gradient Boosting Decision Tree)**
- **Objective**: Binary Classification (1着 or Not)
- **Loss Function**: Binary LogLoss (Weighted by `log1p(win_odds)`)

### 入力データ
- **レース条件**: コース、距離、馬場状態、天候など
- **馬の属性**: 年齢、性別、斤量、馬体重など
- **過去成績**: 着順、タイム、上がり3F、コーナー通過順などの統計値
- **血統**: 父、母父の成績傾向
- **関係者**: 騎手、調教師の成績
- **オッズ**: （学習時のみ重み付けに使用、特徴量としては使用しない）

### 出力
- **`pred_prob`**: 1着になる確率（0.0 ~ 1.0）
- **`rank_pred`**: レース内での予測順位

## 5. 運用フロー
1. **データ取得**: 出馬表データのスクレイピング
2. **特徴量生成**: `FeatureEngine` による特徴量計算
3. **予測**: 学習済みモデル (`mu_v2_7_model.txt`) によるスコアリング
4. **統合**: σモデル、νモデルの結果と合わせて最終的な推奨買い目を決定
