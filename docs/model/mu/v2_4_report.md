# μモデル v2.4 (ROI Restoration) レポート

**作成日**: 2025-11-27
**バージョン**: v2.4
**ベース**: v2.3 (Fixed)
**変更点**: 過剰人気を招く特徴量（生産者、近走成績、騎手×コース相性）の削除

## 1. パフォーマンス比較 (vs v2.3)

| 指標 | v2.3 (Full Features) | v2.4 (Selected Features) | 変化 | 評価 |
|------|-------------------|-----------------------|------|------|
| **ROI (Top1)** | 77.47% | **78.75%** | **+1.28pt** | **改善**。大衆迎合度が下がり、回収率が向上しました。 |
| **Accuracy (Top1)** | 27.36% | **27.82%** | **+0.46pt** | **改善**。ノイズ除去により的中率も微増しました。 |
| **Test AUC** | 0.7787 | **0.7787** (approx) | ±0.00 | 予測精度（順位付け能力）は維持されています。 |

## 2. 削除された特徴量とその影響

以下の特徴量を削除したことで、モデルが「オッズに織り込まれすぎている情報」を無視するようになり、結果として「過剰人気馬」を避ける傾向が強まりました。

1.  **生産者・産地情報** (`breeder_win_rate` 等)
    *   ノーザンファームなどのブランド馬への過剰評価を抑制。
2.  **騎手・調教師の近走成績** (`jockey_recent_win_rate` 等)
    *   「今調子が良い」というニュース性のある（オッズが下がりやすい）情報をカット。
3.  **騎手×競馬場相性** (`jockey_venue_win_rate` 等)
    *   「東京のルメール」のような定石バイアスを排除。

## 3. 結論

v2.4は、v2.3の予測精度（AUC）を維持しつつ、ROIを約1.3%回復させることに成功しました。
これは「特徴量を減らすことで性能が上がる」という、機械学習における**Feature Selection（特徴量選択）の成功事例**です。

今後はこの **v2.4** を正本とし、これをベースにσモデル・νモデルの構築に進むことを推奨します。
