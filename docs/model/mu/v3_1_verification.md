# μモデル v3.1 検証レポート

## 1. 概要
本レポートは、過学習の解消と汎化性能の向上を目的とした v3.1 改修（時系列CV、RFE、正則化強化）の検証結果をまとめたものです。

## 2. 検証結果サマリ

| 指標 | v3.0 (改善前) | **v3.1 (今回)** | 評価 |
| :--- | :--- | :--- | :--- |
| **Validation ROI** | 99.09% | **81.04%** | 現実的な数値に落ち着いた |
| **Test ROI (2024)** | 80.90% | **81.18%** | わずかに向上 |
| **Gap (過学習度)** | 18.19pt | **-0.14pt** | **完全解消 (Overfitting Solved)** |
| **Top 1 Accuracy** | 22.19% | **24.54%** | **+2.35pt 向上** |

### 結論
*   **過学習の解消**: ValidationとTestの乖離がほぼゼロになり、モデルの信頼性が劇的に向上しました。
*   **ベースラインの確立**: フィルタリングなしのベースROIは **約81%** で安定しました。目標の100%には届きませんでしたが、これは「全レース購入」の数値であり、ここからσ・νモデルで選別することで100%超えを目指すための強固な土台が完成しました。

## 3. 実施した対策と効果

1.  **時系列クロスバリデーション (Time-Series CV)**
    *   3つの異なる期間で検証を行うことで、特定の年のトレンドへの過剰適合を防ぎました。
2.  **厳格な特徴量選抜 (RFE)**
    *   特徴量を約170個から **80個** に厳選。
    *   ノイズとなっていた生の体重データ (`horse_weight`, `basis_weight`) を排除し、相対指標 (`_zscore`, `_diff_from_avg`) に一本化しました。
3.  **正則化の強化**
    *   `num_leaves` を制限し、L1/L2正則化を強化したことで、決定木の複雑さが抑制されました。

## 4. 特徴量重要度 (Top 10)

体重の相対指標が引き続き重要ですが、シナジー特徴量もしっかりと寄与しています。

1.  `horse_weight_zscore` (馬体重Zスコア)
2.  `horse_weight_diff_from_avg` (平均との差)
3.  `basis_weight_zscore` (斤量Zスコア)
4.  `weight_diff_from_avg` (体重差分)
5.  `age_zscore` (年齢Zスコア)
6.  `bracket_avg_finish` (枠番平均着順)
7.  `pace_fit_score` (展開適合度)
8.  `bms_avg_finish` (母父平均着順)
9.  `trainer_新潟_win_rate` (調教師コース適性)
10. `bms_win_rate` (母父勝率)

※ `nicks_avg_finish` (50位), `sire_course_avg_finish` (16位) なども採用されています。

## 5. 今後の推奨アクション

ベースモデル (μ) は完成とみなし、次は **収益化フェーズ (σ・νモデル)** に移行することを推奨します。

1.  **σモデル (確信度) の再学習**:
    *   安定した v3.1 のスコアを用いて、的中確率を補正するσモデルを学習させる。
2.  **νモデル (期待値) の構築**:
    *   v3.1 のスコアとオッズを組み合わせて、回収率期待値を予測する。
3.  **シミュレーション**:
    *   2024年のデータで、σ・νフィルタを通したシミュレーションを行い、ROI > 100% を達成できる閾値を探索する。
