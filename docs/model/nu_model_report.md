# νモデル (Nu Estimator) 詳細レポート

**作成日**: 2025-11-25
**バージョン**: v1.0 (Standard)
**目的**: レース全体の「荒れやすさ」を推定する。具体的には、レース結果（着順）の分散（$\nu$）を予測する。

## 1. モデル概要

νモデルは、**LightGBM Regressor**を使用した回帰モデルです。
レースの条件（天候、頭数、オッズのばらつきなど）から、そのレースが波乱になりやすいか、堅く収まりやすいかを予測します。

- **入力**: レース条件、オッズ統計
- **出力**: レース内の着順の標準偏差（Standard Deviation of Finish Positions）
- **用途**: 
  - レース選定（荒れるレースを狙う、または避ける）
  - 資金配分の調整（荒れるレースは広く薄く、堅いレースは絞って厚く）

### 訓練設定
- **訓練データ**: 過去のレース結果
- **目的変数**: `nu_target` = そのレースにおける全馬の着順の標準偏差
- **単位**: レース単位で学習・予測

## 2. ハイパーパラメータ設定

デフォルトのLightGBM回帰パラメータを使用しています。

| パラメータ | 設定値 | 説明 |
|-----------|-------|------|
| `objective` | `regression` | 回帰タスク |
| `metric` | `rmse` | 二乗平均平方根誤差 |
| `boosting_type` | `gbdt` | 勾配ブースティング決定木 |
| `learning_rate` | 0.05 | 標準的な学習率 |
| `n_estimators` | 100 | 木の数（軽量モデル） |
| `num_leaves` | 31 | 葉の数 |

## 3. 特徴量詳細 (全7個)

νモデルは、レースの環境やメンバー構成に関する特徴量を使用します。
これらの要素が組み合わさることで「荒れやすさ」が決まります。

| 特徴量名 | 説明 | なぜ重要か？ |
|---|---|---|
| `std_win_odds` | 単勝オッズの標準偏差 | **[最重要]** オッズが拮抗している（標準偏差が小さい）レースは混戦になりやすく、荒れる可能性が高まります。 |
| `avg_win_odds` | 単勝オッズの平均 | 本命不在か、圧倒的1番人気がいるかなど、メンバーのレベル感を示します。 |
| `head_count` | 出走頭数 | 頭数が多いほど紛れ（不利や展開のアヤ）が生じやすく、着順の分散が大きくなる傾向があります。 |
| `track_condition` | 馬場状態 (良/稍重/重/不良) | 悪天候や不良馬場は波乱の大きな要因となります。 |
| `weather` | 天候 | 雨や雪は視界や馬場に影響し、不確定要素を増やします。 |
| `distance_m` | 距離 | 短距離は一瞬の判断ミスが命取りになりやすく、長距離はスタミナ切れなど、距離によって荒れ方が異なります。 |
| `track_surface` | トラック種別 (芝/ダート) | 芝とダートでは波乱の傾向が異なります（一般にダートの方が堅いと言われます）。 |

## 4. データ処理パイプライン

1. **レース集約**: レースごとに着順の標準偏差（`nu_target`）を計算
2. **特徴量生成**: レース条件やオッズ統計を計算
3. **カテゴリ処理**: `track_surface`, `track_condition`, `weather` をOne-Hotエンコーディング
4. **訓練**: LightGBMで学習
5. **保存**: `nu_model.pkl` として保存

## 5. 運用上の注意点

- **オッズ依存**: オッズ統計を使用しているため、**直前オッズ**を使用することで精度が向上します。前日オッズでは精度が落ちる可能性があります。
- **季節性**: 天候や馬場状態は季節によって傾向が変わるため、通年データでの学習が重要です。
