# σモデル (Sigma Estimator) 詳細レポート

**作成日**: 2025-11-25
**バージョン**: v1.0 (Standard)
**目的**: 各馬の予測精度（不確実性）を推定する。具体的には、μモデルの予測誤差の分散（$\sigma^2$）を予測する。

## 1. モデル概要

σモデルは、**LightGBM Regressor**を使用した回帰モデルです。
μモデルが「どの馬が勝つか」を予測するのに対し、σモデルは「**その予測がどれくらい外れそうか**」を予測します。

- **入力**: 馬の過去成績の統計値（平均着順、着順のばらつきなど）
- **出力**: 予測誤差の二乗（Squared Error）の期待値
- **用途**: 
  - 予測の信頼区間の計算
  - 期待値（EV）計算時のリスク評価
  - 荒れるレースの特定（νモデルと併用）

### 訓練設定
- **訓練データ**: 過去のレース結果と、それに対するμモデルの予測値
- **目的変数**: `squared_error` = (実際の着順 - μモデルの予測着順)^2
- **集約**: 馬ごとに `squared_error` の平均を計算し、それをターゲットとする（馬固有の誤差傾向を学習）

## 2. ハイパーパラメータ設定

デフォルトのLightGBM回帰パラメータを使用しています。

| パラメータ | 設定値 | 説明 |
|-----------|-------|------|
| `objective` | `regression` | 回帰タスク |
| `metric` | `rmse` | 二乗平均平方根誤差 |
| `boosting_type` | `gbdt` | 勾配ブースティング決定木 |
| `learning_rate` | 0.05 | 標準的な学習率 |
| `n_estimators` | 100 | 木の数（軽量モデル） |
| `num_leaves` | 31 | 葉の数 |

## 3. 特徴量詳細 (全4個)

σモデルは、馬の「安定感」を表す統計的特徴量を使用します。
非常にシンプルなモデルですが、各特徴量の役割は明確です。

| 特徴量名 | 説明 | なぜ重要か？ |
|---|---|---|
| `std_finish_pos` | 過去の着順標準偏差 | **[最重要]** 過去に着順が暴れている馬は、将来も予測誤差が大きくなる傾向があります。 |
| `mean_finish_pos` | 過去の平均着順 | 強い馬（平均着順が良い）ほど、予測が安定する傾向があります。 |
| `total_races` | 総出走回数 | 出走回数が少ない馬はデータ不足により予測が不安定になるため、誤差が大きくなる傾向を学習します。 |
| `age` | 馬齢 | 若馬は成長途上で不安定、高齢馬は衰えで不安定といった傾向を捉えます。 |

## 4. データ処理パイプライン

1. **μ予測の取得**: 過去のレースに対してμモデルで予測を実行
2. **誤差計算**: 実際の着順との差の二乗を計算
3. **馬単位集約**: 馬ごとに誤差の平均（`sigma_target`）を計算
4. **特徴量結合**: 馬の統計特徴量を結合
5. **訓練**: LightGBMで学習
6. **保存**: `sigma_model.pkl` として保存

## 5. 運用上の注意点

- **μモデル依存**: μモデルが更新された場合、誤差の傾向が変わるため、**必ずσモデルも再訓練**する必要があります。
- **データ更新**: 定期的に最新のレース結果を取り込み、馬の「現在の安定性」を反映させる必要があります。
