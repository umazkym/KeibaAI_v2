## FeatureEngine クラス

```python
class FeatureEngine:
    def __init__(self, config_or_path):
        """
        レシピベースの特徴量生成エンジン
        Args:
            config_or_path: features.yamlへのパス または 設定辞書
        """
        self.config = config
        self.recipes = self.config.get('feature_recipes', {})

    def generate_features(
        self,
        shutuba_df: pd.DataFrame,
        results_history_df: pd.DataFrame,
        horse_profiles_df: pd.DataFrame,
        pedigree_df: Optional[pd.DataFrame] = None,
    ) -> pd.DataFrame:
        """特徴量生成メインフロー (v2.1)"""

        # 1. 前処理: 血統ID抽出・プロファイルマージ
        df = self._preprocess(shutuba_df, horse_profiles_df, pedigree_df)

        # 2. レシピベース生成 (Basic, Career, Past, Interaction...)
        if self.recipes.get('basic_features', {}).get('enabled'):
            df = self._add_basic_features(df)
        
        # ... (各レシピの実行) ...

        # 3. 高度な特徴量 (AdvancedFeatureEngine)
        # Phase D: コース適性・レース条件・相対指標
        if adv_engine:
             df = adv_engine.generate_course_affinity_features(df, ...)
             df = adv_engine.calculate_relative_metrics(df)

        # 4. ROI特化型特徴量 (ROIFeatureEngine)
        # Phase E: 投資戦略向け微調整
        if roi_engine:
             df = roi_engine.generate_features(df, ...)

        # 5. 後処理: 欠損値補完・ターゲット除外
        df = self._handle_missing_values(df)
        self.feature_names_ = self._select_features(df)

        return df
```

### 主要コンポーネント詳細

#### 1. レシピベース生成 (`_add_*`)
`features.yaml` の定義に従って動的に処理をディスパッチします。
*   `_add_basic_features`: カテゴリ変数のOne-Hot化、枠番カテゴリ化
*   `_add_past_performance_features`: 過去走集約 (avg_finish_last3 等)
*   `_add_interaction_features`: 騎手×コース相性などの交互作用

#### 2. AdvancedFeatureEngine (高度特徴量)
`keibaai/src/features/advanced_features.py` に実装された、より複雑なロジックを担当します。
*   **コース適性**: `venue_avg_finish`, `dist_avg_finish`
*   **レース内相対指標**: `horse_weight_zscore`, `odds_rank`
*   **バイアス分析**: 季節性バイアス、フィールドサイズ影響

#### 3. ROIFeatureEngine (ROI最適化)
`keibaai/src/features/roi_features.py` に実装された、利益率向上のための実験的指標です。

## 📈 特徴量重要度 (v2.6)

### 上位推奨特徴量 (Binary Model)

| ランク | 特徴量 | カテゴリ | 理由 |
|-------|-------|---------|------|
| 1 | `past_1_finish_position` | 過去走 | 前走着順は最強の予測因子 |
| 2 | `win_rate_last5` | 過去走 | 近走の勝率は安定性を反映 |
| 3 | `jockey_win_rate` | 騎手 | 騎手実力は無視できないファクター |
| 4 | `horse_weight_zscore` | 相対 | レース内での馬格の優位性 |
| 5 | `venue_avg_finish` | 適性 | コース巧者は人気以上の激走要因 |

> [!WARNING]
> **除外対象 (リーク防止)**
> 以下のカラムは学習時に厳密に除外されます（`_select_features` メソッドでフィルタリング）。
> *   `win_odds`, `popularity` (確定オッズ/人気)
> *   `finish_position`, `finish_time_seconds` (結果)
> *   `popularity_finish_diff`, `relative_odds` (オッズ由来)

## 📦 μv2.0 追加特徴量（48特徴量）

**最終更新**: 2025-11-24  
**実装**: `keibaai/src/features/mu_v2_features.py`

### 目的

従来のμ/σ/νモデルに加え、**1着予測に特化した分類モデル**として開発。完全にデータリークを排除しつつ、的中率25.89%（ランダムの3.6倍）を達成。

### カテゴリ構成（全6カテゴリ、48特徴量）

#### カテゴリ1: 安定性・経験値（8特徴量）
馬の成績の安定性と経験を定量化。

| 特徴量 | 説明 | 計算方法 |
|-------|------|---------|
| `horse_finish_cv_last5` | 過去5走の変動係数 | std / mean |
| `horse_finish_range_last5` | 過去5走の最大最小差 | max - min |
| `horse_finish_trend_last5` | 過去5走のトレンド | 線形回帰の傾き |
| `horse_top3_rate_last10` | 過去10走の好走率 | 3着以内の割合 |
| `horse_experience_log` | 経験値（対数） | log(総レース数 + 1) |
| `jockey_finish_cv_last10` | 騎手の変動係数 | 過去10走のCV |
| `jockey_consistency_score` | 騎手の安定性スコア | 1 / (CV + 0.01) |
| `trainer_finish_cv_last10` | 調教師の変動係数 | 過去10走のCV |

#### カテゴリ2: 条件適性（15特徴量）
距離、馬場、コース、天候ごとの成績。

| 特徴量 | 説明 |
|-------|------|
| `horse_{条件}_avg_finish` | 馬の条件別平均着順 |
| `horse_{条件}_win_rate` | 馬の条件別勝率 |
| `jockey_{条件}_win_rate` | 騎手の条件別勝率 |
| `distance_avg_finish` | 距離別平均着順 |
| `surface_avg_finish` | 馬場別平均着順 |
| `weather_avg_finish` | 天候別平均着順 |
| `condition_avg_finish` | 複合条件（距離×馬場）の平均着順 |

**条件**: 距離（`sprint`, `mile`, `intermediate`, `long`）、馬場（`芝`, `ダート`）、競馬場、馬場状態、天候

#### カテゴリ3: ペース適性（10特徴量）
脚質と展開予想。

| 特徴量 | 説明 |
|-------|------|
| `horse_early_position` | 序盤の位置取り（過去平均） |
| `horse_running_style` | 脚質（逃げ/先行/差し/追込） |
| `horse_avg_last_3f` | 平均上がり3F |
| `fast_pace_affinity` | 速いペースでの成績 |
| `slow_pace_affinity` | 遅いペースでの成績 |
| `race_expected_pace` | レース予想ペース |
| `horse_closing_kick_avg` | 差し脚スコア |

⚠️ **リーク回避**: `passing_order`, `last_3f_time`, `pace_index` などレース結果由来のデータは除外

#### カテゴリ4: 騎手・調教師相性（8特徴量）
組み合わせ効果。

| 特徴量 | 説明 |
|-------|------|
| `jockey_horse_avg_finish` | 騎手×馬の平均着順 |
| `jockey_horse_win_rate` | 騎手×馬の勝率 |
| `trainer_horse_avg_finish` | 調教師×馬の平均着順 |
| `trainer_horse_win_rate` | 調教師×馬の勝率 |
| `jockey_trainer_avg_finish` | 騎手×調教師の平均着順 |
| `jockey_new_avg_finish` | 騎手×馬（初騎乗）の平均着順 |
| `jockey_継続_avg_finish` | 騎手×馬（継続騎乗）の平均着順 |

#### カテゴリ5: 血統詳細（12特徴量）
父・母父の産駒適性（世代IDベース）。

| 特徴量 | 説明 | 実装ポイント |
|-------|------|------------|
| `sire_dist_avg_finish` | 父の産駒の距離別平均着順 | `pedigrees.parquet` から世代1の1番目（父） |
| `sire_surf_avg_finish` | 父の産駒の馬場別平均着順 | 同上 |
| `damsire_dist_avg_finish` | 母父の産駒の距離別平均着順 | 世代2の3番目（母父） |
| `damsire_surf_avg_finish` | 母父の産駒の馬場別平均着順 | 同上 |

**重要**: 「親の勝率」ではなく「産駒の適性」を使用。これにより **実際に上位（16位、20位）にランクイン**。

#### カテゴリ6: レース間隔（5特徴量）
休養と調整。

| 特徴量 | 説明 |
|-------|------|
| `days_since_last_race` | 前走からの日数 |
| `is_after_long_rest` | 90日以上の休養明けフラグ |
| `is_after_mid_rest` | 30-90日の休養フラグ |
| `weight_change_from_last` | 前走からの体重変化 |
| `weight_change_pct` | 前走からの体重変化率 |

### データリーク防止の実装

#### ローリングウィンドウ方式

```python
# train_mu_v2_model.py
for month in range(start, end):
    # Target: 今月のレース
    target_df = df[(df['race_date'] >= month_start) & (df['race_date'] < month_end)]
    
    # History: 今月より前のデータのみ
    history_df = df[df['race_date'] < month_start]
    
    # 特徴量生成（Historyのみ使用）
    features = generate_features(target_df, history_df)
```

#### 除外したリーク源（8種類）

1. `final_corner_to_finish` - 最終コーナー→ゴールの順位変動
2. `pace_index` - レースペース指数
3. `passing_order_1-4` - 通過順位
4. `last_3f_time` - 上がり3F
5. `time_except_last3f` - 上がり以外のタイム
6. `position_change_*` - 位置取り変動
7. `win_probability` - 確定オッズ由来の勝率
8. `finish_time_seconds` - ゴールタイム
