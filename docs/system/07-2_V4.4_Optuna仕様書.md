## 4. モデル設計

### 4.1 アルゴリズム

- **モデル**: LightGBM LGBMRanker
- **目的関数**: LambdaRank
- **評価指標**: NDCG@1, 3, 5

### 4.2 Optuna最適化

**最適化対象**:
- `num_leaves`, `max_depth`, `min_child_samples`
- `learning_rate`, `reg_alpha`, `reg_lambda`
- `feature_fraction`, `bagging_fraction`, `bagging_freq`

**目的関数**:
```python
score = valid_roi - gap * 0.5
```
Gap拡大にペナルティを課して過学習を抑制。

### 4.3 最適パラメータ

```python
{
    'num_leaves': 39,
    'max_depth': 6,
    'min_child_samples': 141,
    'learning_rate': 0.097,
    'reg_alpha': 1.70,
    'reg_lambda': 3.63,
    'feature_fraction': 0.61,
    'bagging_fraction': 0.60,
    'bagging_freq': 6
}
```

### 4.4 ターゲット変数

LambdaRank用のゲイン値として、着順とオッズを考慮した重み付け:

```python
gain[1着] = log(1 + odds) * 12.74
gain[2着] = log(1 + odds) * 6.73
gain[3着] = log(1 + odds) * 3.69
gain[4着以下] = 0
```

高配当の的中がより高く評価される。

## 5. 評価方法

### 5.1 ROI計算

各レースで最もスコアが高い馬に単勝100円を賭けた場合のROI:

```
ROI = (的中レースのオッズ合計) / (賭けたレース数) × 100
```

## 10. V4.4 Residual（残差学習版）【2025-12-24追記】

> [!IMPORTANT]
> **V4.4オリジナルの過学習問題は「残差学習」により完全解決しました**

### 10.1 問題
V4.4オリジナルはTrain-Test Gap 64.7%という深刻な過学習問題を抱えていました。

### 10.2 解決策：残差学習 (Residual Learning)
V15 Fixedの予測結果を利用し、**「V15が過小評価したのに勝った馬」**だけをターゲットに学習。

```python
# ターゲット計算
residual = actual_result - v15_prediction
target = residual * log(1 + odds)  # 残差 × オッズ重み
```

### 10.3 検証結果（4年平均）

| モデル | ROI | Gap | σ | 評価 |
|--------|-----|-----|-----|------|
| V15 Fixed | 82.8% | 25.5% | 3.7% | 安定 |
| V4.4 Orig | 84.5% | 64.7% | 6.5% | ❌過学習 |
| **V4.4 Residual** | 82.6% | **31.8%** | **2.2%** | ✅解決 |
| **Ensemble** | **83.9%** | **26.9%** | 3.4% | **推奨** |

### 10.4 最終推奨構成
**V15 Fixed + V4.4 Residual の50:50アンサンブル**が現在の推奨モデルです。
詳細は [07_機械学習モデル.md](./07_機械学習モデル.md) を参照。
