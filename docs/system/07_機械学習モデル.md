## 🎯 モデル概要

### 予測目標

従来の着順予測（分類問題）ではなく、**確率分布の推定**：

```python
# ❌ 従来の分類モデル
y_pred = [1, 5, 3, 2, ...]  # 各馬の予測着順

# ✅ KeibaAI_v2の確率モデル
μ = [72.3, 73.1, 71.8, ...]  # 期待完走時間（秒）
σ = [1.2, 2.5, 0.8, ...]     # 馬固有の不確実性（秒）
ν = 5.0                      # レース全体の混沌度（自由度）

# → t分布でモデル化
# → モンテカルロで勝率推定
P(win) = [0.35, 0.12, 0.42, ...]
```

## 🔬 3パラメータモデル（μ, σ, ν）

### 数学的背景

各馬iの完走時間を**t分布**でモデル化：

```
T_i ~ t_ν(μ_i, σ_i²)

where:
  μ_i: 馬iの期待完走時間（location parameter）
  σ_i: 馬iの標準偏差（scale parameter）
  ν:   レース全体の自由度（degrees of freedom）
```

**t分布を選ぶ理由**:
1. 外れ値に頑健（heavy-tailed）
2. νが小さい → 予想外の展開が起きやすい（荒れるレース）
3. νが大きい → 正規分布に近づく（堅いレース）

### パラメータの解釈

| パラメータ | 意味 | 典型値 | 影響要因 |
|-----------|------|-------|---------|
| **μ（mu）** | 期待完走時間 | 70-150秒 | 距離、馬の能力、騎手 |
| **σ（sigma）** | 馬固有の不確実性 | 0.5-3.0秒 | 馬の安定性、経験 |
| **ν（nu）** | レース全体の混沌度 | 3-10 | レースクラス、馬場状態 |

### μモデル（期待完走時間）

**ファイル**: `keibaai/src/models/model_train.py`

#### アプローチ

**2段階学習**:
1. **Ranking**: 相対的な強さを学習（LambdaRank）
2. **Regression**: 絶対的なタイムを学習（RMSE最小化）

```python
import numpy as np
from lightgbm import LGBMRanker, LGBMRegressor

class MuEstimator:
    def __init__(self, ranker_params=None, regressor_params=None):
        # Stage 1: Ranking（相対的な強さを学習）
        self.ranker_params = ranker_params or {
            'objective': 'lambdarank',
            'metric': 'ndcg',
            'n_estimators': 1000,
            'learning_rate': 0.01,
            'num_leaves': 31,
            'verbose': -1
        }
        
        # Stage 2: Regression（絶対的なタイムを学習）
        self.regressor_params = regressor_params or {
            'objective': 'regression',
            'metric': 'rmse',
            'n_estimators': 1000,
            'learning_rate': 0.01,
            'num_leaves': 31,
            'verbose': -1
        }
        
        self.ranker = None
        self.regressor = None

    def fit(self, X, y, group):
        """
        Args:
            X: 特徴量 [N x D]
            y: 完走時間（秒） [N]
            group: レースごとの馬数 [num_races]
        """
        # Stage 1: Rankerの学習
        # yは完走時間（浮動小数点）なので、整数のrelevanceスコアに変換
        rank_target = []
        start_idx = 0
        for g in group:
            group_y = y[start_idx:start_idx+g]
            # タイムからランクを計算（0-indexed）
            ranks = np.argsort(np.argsort(group_y))
            # relevance: 最大ランク - 現在のランク（1着が最高スコア）
            relevance = (g - 1) - ranks
            rank_target.extend(relevance)
            start_idx += g
        rank_target = np.array(rank_target, dtype=int)
        
        # Rankerの学習
        self.ranker = LGBMRanker(**self.ranker_params)
        self.ranker.fit(X, rank_target, group=group)
        rank_scores = self.ranker.predict(X)

        # Stage 2: Regressorの学習
        X_aug = X.copy()
        X_aug['rank_score'] = rank_scores  # Rankerのスコアを特徴量に追加
        
        self.regressor = LGBMRegressor(**self.regressor_params)
        self.regressor.fit(X_aug, y)

    def predict(self, X):
        rank_scores = self.ranker.predict(X)
        X_aug = X.copy()
        X_aug['rank_score'] = rank_scores
        mu = self.regressor.predict(X_aug)
        return mu
```

**重要な実装ポイント**:
- `LGBMRanker`は整数型のrelevanceスコアを要求するため、完走時間（浮動小数点）から各レース内でランクを計算
- `(最大ランク - 現在のランク)`で1着が最高スコアになるように変換
- Rankerのスコアを特徴量に追加することで、相対的な強さと絶対的なタイムの両方を学習

### 2. Expected Calibration Error (ECE)

```python
def calculate_ece(y_true, y_prob, n_bins=10):
    """
    Expected Calibration Error

    確率の予測値と実際の勝率のズレを測定
    """
    bins = np.linspace(0, 1, n_bins + 1)
    bin_indices = np.digitize(y_prob, bins) - 1

    ece = 0.0
    for i in range(n_bins):
        mask = bin_indices == i
        if mask.sum() > 0:
            avg_prob = y_prob[mask].mean()
            avg_true = y_true[mask].mean()
            ece += mask.sum() / len(y_true) * abs(avg_prob - avg_true)

    return ece
```

**解釈**:
- ECE < 0.05: 非常によく校正されている
- 0.05 - 0.10: 許容範囲
- > 0.10: 校正が必要

### 3. ROI（投資収益率）

```python
def calculate_roi(bets, outcomes, odds):
    """
    Return on Investment

    Args:
        bets: 賭け金配分 [N]
        outcomes: 結果（1=的中, 0=外れ） [N]
        odds: オッズ [N]

    Returns:
        ROI: 投資収益率
    """
    total_bet = bets.sum()
    total_return = (bets * outcomes * odds).sum()

    roi = total_return / total_bet
    return roi
```

**解釈**:
- ROI > 1.0: 利益
- ROI = 1.0: 損益分岐点
- ROI < 1.0: 損失

# 1着予測の的中率

## 🏆 アンサンブル学習（StackingEnsemble）

**ファイル**: `keibaai/src/models/stacking_ensemble.py`

複数のベースモデルの予測を組み合わせて、より頑健で高精度な予測を実現します。

### アーキテクチャ

```
Level 0 (Base Models):
┌──────────┐  ┌──────────┐  ┌──────────┐
│ Model 1  │  │ Model 2  │  │ Model 3  │
│(LightGBM)│  │(LightGBM)│  │(LightGBM)│
└─────┬────┘  └─────┬────┘  └─────┬────┘
      │             │             │
      └──────┬──────┴──────┬──────┘
             │  Out-of-Fold │
             │  Predictions │
             ▼             ▼
      ┌────────────────────────┐
      │ Level 1 (Meta Model)  │
      │  Ridge Regression     │
      └───────────┬────────────┘
                  │
                  ▼
           Final Prediction
```

### 使用方法

```python
from keibaai.src.models.stacking_ensemble import StackingEnsemble
from lightgbm import LGBMRegressor

# ベースモデルの定義（異なる設定）
base_models = [
    LGBMRegressor(n_estimators=1000, learning_rate=0.01, num_leaves=31),
    LGBMRegressor(n_estimators=1500, learning_rate=0.005, num_leaves=63),
    LGBMRegressor(n_estimators=800, learning_rate=0.02, num_leaves=15)
]

# アンサンブルモデルの学習
ensemble = StackingEnsemble(base_models=base_models, n_folds=5)
ensemble.fit(X_train, y_train)

# 予測
y_pred = ensemble.predict(X_test)
```

### アンサンブルの利点

1. **分散の削減**: 複数モデルの平均化により過学習を抑制
2. **バイアスの補正**: メタモデルが各ベースモデルの弱点を補完
3. **頑健性の向上**: 単一モデルの失敗リスクを軽減
