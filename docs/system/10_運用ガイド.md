## 🚀 セットアップ

### 環境構築

#### 1. リポジトリクローン

```bash
git clone https://github.com/umazkym/KeibaAI_v2.git
cd KeibaAI_v2
```

#### 2. Python環境構築

```bash
# Python 3.10+ 推奨
python --version  # 3.10以上を確認

# 仮想環境作成
python -m venv venv

# 仮想環境有効化
source venv/bin/activate  # Linux/Mac
# または
venv\Scripts\activate  # Windows

# 依存パッケージインストール
pip install -r requirements.txt
```

#### 3. ディレクトリ作成

```bash
# データディレクトリ作成
mkdir -p keibaai/data/{raw/html/{race,shutuba,horse,ped},parsed/parquet/{races,shutuba,horses,pedigrees},features/parquet,models,simulations,orders,logs,metadata}
```

#### 4. 設定ファイル確認

```bash
# YAML設定ファイルの確認
ls keibaai/configs/
# default.yaml, scraping.yaml, features.yaml, models.yaml, optimization.yaml
```

## 📅 日次運用フロー

### スケジュール（Cron設定例）

```bash
# /etc/crontab または crontab -e

# 深夜3:00 - 前日レース結果スクレイピング
0 3 * * * cd /path/to/KeibaAI_v2 && python scripts/pipelines/run_scraping_resumable.py >> /var/log/keibaai/scraping.log 2>&1

# 深夜4:00 - パース処理
0 4 * * * cd /path/to/KeibaAI_v2 && python scripts/pipelines/run_parsing_resumable.py >> /var/log/keibaai/parsing.log 2>&1

# 深夜4:30 - 特徴量生成
30 4 * * * cd /path/to/KeibaAI_v2 && python scripts/pipelines/generate_features.py --date $(date -d yesterday +\%Y-\%m-\%d) >> /var/log/keibaai/features.log 2>&1

# 深夜5:00 - データ品質チェック（自動）
0 5 * * * cd /path/to/KeibaAI_v2 && python scripts/maintenance/run_quality_checks.py --config keibaai/configs/default.yaml >> /var/log/keibaai/quality_check.log 2>&1

# 朝10:00 - 当日レース予測
0 10 * * * cd /path/to/KeibaAI_v2 && python scripts/training/predict.py --date $(date +\%Y-\%m-\%d) >> /var/log/keibaai/predict.log 2>&1

# 日曜夜23:00 - モデル再訓練（レガシーパス）
0 23 * * 0 cd /path/to/KeibaAI_v2 && python scripts/training/train_mu_model.py >> /var/log/keibaai/train.log 2>&1
# または新世代モデル: scripts/training/train_mu_v2_model.py

# 月曜朝9:00 - 週次モデル分析レポート生成
0 9 * * 1 cd /path/to/KeibaAI_v2 && python scripts/analysis/run_quality_checks.py --model-analysis-only --model-dir keibaai/data/models/latest --predictions keibaai/data/predictions/latest.parquet --actuals keibaai/data/parsed/parquet/races/races.parquet >> /var/log/keibaai/model_analysis.log 2>&1
```

### 手動実行手順

#### Phase 0: スクレイピング

```bash
# 前日のレース結果取得
python scripts/pipelines/run_scraping_resumable.py

# または特定日付を指定
python scripts/pipelines/run_scraping_resumable.py --from 2023-10-01 --to 2023-10-01
```

#### Phase 1: パース

```bash
# 全HTMLファイルをパース
python scripts/pipelines/run_parsing_resumable.py

# パース結果の確認
python scripts/debug/check_all_parquet.py
```

#### Phase 2: 特徴量生成

```bash
# 特定期間の特徴量生成
python scripts/pipelines/generate_features.py \
  --start_date 2023-01-01 \
  --end_date 2023-12-31

# 特徴量の確認
python check_features_data.py
```

#### Phase 3: モデル訓練

```bash
# μモデルの訓練（レガシー）
python scripts/training/train_mu_model.py \
  --start_date 2020-01-01 \
  --end_date 2023-09-30 \
  --output_dir keibaai/data/models/20231001_lgbm

# μv2.0モデルの訓練（レガシー）
# 最新の推奨モデルは V15 + V4.4 Residual Ensemble です
python scripts/training/train_mu_v2_model.py

# モデルの評価
python scripts/training/evaluate_model.py \
  --model_path keibaai/data/models/20231001_lgbm/mu_model.txt \
  --test_date_start 2023-10-01 \
  --test_date_end 2023-10-31
```

#### Phase 4: 予測

```bash
# 当日レースの予測
python scripts/training/predict.py \
  --date 2023-10-01 \
  --model_dir keibaai/data/models/20231001_lgbm
```

#### Phase 5: シミュレーション

```bash
# 当日レースのシミュレーション
python keibaai/src/sim/simulate_daily_races.py \
  --date 2023-10-01 \
  --K 1000
```

#### Phase 6: 最適化

```bash
# 当日レースの最適化
python keibaai/src/optimizer/optimize_daily_races.py \
  --date 2023-10-01 \
  --W_0 100000
```

## 💾 バックアップとリカバリ

### バックアップ対象

| データ | 頻度 | 重要度 | バックアップ先 |
|-------|------|-------|--------------|
| **生HTML** (`data/raw/html/`) | 週次 | 高 | 外部HDD/クラウド |
| **パース済みParquet** (`data/parsed/`) | 日次 | 中 | 外部HDD |
| **特徴量** (`data/features/`) | 週次 | 低（再生成可能） | - |
| **モデル** (`data/models/`) | モデル更新時 | 高 | Git LFS/クラウド |
| **設定ファイル** (`configs/`) | Git管理 | 高 | GitHub |
| **メタデータDB** (`metadata/db.sqlite3`) | 日次 | 中 | 外部HDD |

### バックアップスクリプト

```bash
#!/bin/bash
# backup_daily.sh

BACKUP_DIR="/mnt/external/keibaai_backup/$(date +%Y%m%d)"
mkdir -p $BACKUP_DIR

# 生HTMLのバックアップ（週次）
if [ $(date +%u) -eq 7 ]; then  # 日曜日
    tar -czf $BACKUP_DIR/raw_html.tar.gz keibaai/data/raw/html/
fi

# パース済みデータのバックアップ
cp -r keibaai/data/parsed/parquet/ $BACKUP_DIR/

# メタデータDBのバックアップ
cp keibaai/data/metadata/db.sqlite3 $BACKUP_DIR/

# 古いバックアップの削除（30日以上前）
find /mnt/external/keibaai_backup/ -type d -mtime +30 -exec rm -rf {} \;
```

### リカバリ手順

#### ケース1: 生HTMLが破損

```bash
# バックアップから復元
tar -xzf /mnt/external/keibaai_backup/20231001/raw_html.tar.gz -C keibaai/data/

# 再パース
python scripts/pipelines/run_parsing_resumable.py
```

#### ケース2: Parquetファイルが破損

```bash
# バックアップから復元
cp -r /mnt/external/keibaai_backup/20231001/parsed/ keibaai/data/

# または生HTMLから再パース
python scripts/pipelines/run_parsing_resumable.py
```

#### ケース3: モデルが破損

```bash
# Git LFSから復元
git lfs pull

# または再訓練
python scripts/training/train_mu_model.py
```

## 🎯 ベストプラクティス

### 1. 定期的なデータ品質チェック

```bash
# 毎週月曜日にデータ品質チェック
# crontab -e
0 9 * * 1 cd /path/to/KeibaAI_v2 && python scripts/debug/check_all_parquet.py | mail -s "Data Quality Report" admin@example.com
```

### 2. モデルの定期再訓練

- 週次: 直近1週間のデータを追加して再訓練
- 月次: ハイパーパラメータチューニング
- 四半期: アーキテクチャ見直し

### 3. ログローテーション

```bash
# logrotate設定
# /etc/logrotate.d/keibaai
/var/log/keibaai/*.log {
    daily
    rotate 30
    compress
    missingok
    notifempty
}
```

### 4. アラート設定

```bash
# エラー発生時にメール通知
# crontab -e
*/30 * * * * cd /path/to/KeibaAI_v2 && grep ERROR keibaai/data/logs/keibaai_$(date +\%Y\%m\%d).log | tail -1 | mail -s "KeibaAI Error Alert" admin@example.com
```
