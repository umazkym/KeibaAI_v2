## 📊 検証概要

2020-2025年の6年間Walk-forward検証を実施し、21条件でのROI・的中率・安定性を評価しました。

| 項目 | 値 |
|:-----|---:|
| 検証期間 | 2020-2025年 |
| 総レース数 | 約20,733件 |
| 検証条件数 | 21条件 |
| 使用モデル | LeakFreeFeatureEngineerV33 |

## 🎯 条件別6年間ROI サマリー

### ROI上位条件（平均ROI順）

| 条件 | 平均ROI | σ | 最低 | 最高 | 総件数 | 評価 |
|:-----|--------:|---:|-----:|-----:|-------:|:-----|
| **三連複 10-20倍** | 95.5% | 51.5 | 35.6% | 169% | 2,401 | ★変動大だが高ROI |
| **複勝 1-5倍** | 83.2% | 1.1 | 82.1% | 84.7% | 11,580 | ★★最安定 |
| 馬単 20-50倍 | 81.4% | 145 | 0% | 375% | 1,217 | 変動大 |
| **馬連 10-20倍** | 80.1% | 40.6 | 31% | 137% | 2,401 | ★有望株 |
| **単勝 10-20倍** | 80.1% | 14.1 | 60.6% | 98.4% | 2,401 | ★安定 |

### 重要な発見

1. **6年間で一貫してROI 100%超の条件は存在しない**
   - 三連複10-20倍は2020-2022年に100%超だったが、2023年以降は急落
   - 条件の有効期限が存在する可能性

2. **安定性と高ROIはトレードオフ**
   - 複勝1-5倍: σ=1.1で最も安定だが、ROI 83%が上限
   - 三連複10-20倍: σ=51.5で変動大だが、平均ROI 96%

3. **年次変動を考慮した資金管理が必須**

## 🔍 敗因分析サマリー（2020-2025年全レース）

### 競馬場別ROI

| 競馬場 | ROI | 的中率 | 評価 |
|:------:|----:|-------:|:-----|
| **小倉** | 87.6% | - | ★最高 |
| 福島 | 69.7% | 16.7% | ★最低 |

**洞察**: 競馬場間でROI変動が約18%存在。競馬場別チューニング余地あり。

### 頭数別分析

| 頭数帯 | 件数 | 的中率 | ROI |
|:------:|-----:|-------:|----:|
| 少頭数(~8頭) | 1,224 | **29.7%** | 77.6% |
| 超多頭数(17頭~) | 1,706 | **17.7%** | 74.3% |

**洞察**: 頭数が増えると的中率は低下するが、ROIへの影響は限定的（±3%程度）。

### オッズ分布と的中率

| 1番人気オッズ | 件数 | 的中率 |
|:-------------|-----:|-------:|
| 1-2倍 | 4,744 | **29.9%** |
| 3-5倍 | 6,744 | 14.8% |

**洞察**: 1番人気低オッズレースは予測しやすい。馬単/三連単で2-3着穴馬を狙う戦略が有効。

## 💡 深い推論: ユーザーレビュー踏まえた発見

### 推論1: オッズ拮抗レースでの穴馬発見能力

| 項目 | 値 |
|:-----|---:|
| 穴馬(6番人気以下)をTop1選出で的中 | **3.99%** (40件/1,003件) |
| 平均払戻 | **18.6倍** |

**洞察**: 人間が見つけ辛い穴馬を約4%の確率で発見し、高配当を獲得。

### 推論2: 1番人気低オッズ時の2-3着穴馬出現率

| 順位 | 穴馬(6番人気以下)出現率 |
|:-----|------------------------:|
| 2着 | 19.8% |
| 3着 | 31.7% |
| 平均 | **25.7%** |

**洞察**: 1番人気低オッズレースでも2-3着の4分の1は穴馬。馬単/三連単で狙える。

### 推論3: レースの「荒れ度」による戦略使い分け

| 1番人気オッズ | 荒れ率 | 推奨戦略 |
|:-------------|-------:|:---------|
| ~1.5倍 | 3.1% | 馬単/三連単で2-3着穴馬狙い |
| 2-3倍 | 15.7% | 穴馬単勝狙い(10-20倍帯) |
| **3倍+** | **24.3%** | 複勝でリスクヘッジ |

### 推論4: 馬単ROI（1番人気オッズ帯別）

| オッズ帯 | 的中率 | ROI | 評価 |
|:---------|-------:|----:|:-----|
| **2.0-3.0倍** | 3.44% | **83.7%** | ★最高効率 |
| 1.0-1.5倍 | 10.83% | 53.5% | 低ROI |

## 🚀 次のステップ（アクション案）

### Phase 1: モデルチューニングによるROI向上

#### 1.1 競馬場×芝ダート×距離帯別のモデルチューニング

```
現状: 競馬場間ROI差18%（小倉87.6% vs 福島69.7%）
目標: 苦手競馬場のROIを+5%改善

アプローチ:
- 競馬場×芝ダート×距離帯（短距離/マイル/中距離/長距離）の組み合わせ別に学習
- 得意条件に絞って賭けることでROI向上
- 苦手条件（福島ダート等）は賭け金を減らすか見送り
```

#### 1.2 得意条件フィルタリング

```
得意条件の例:
- 小倉×芝×1200-1800m → ROI 87%+
- 東京×ダート×1600m → 類似分析が必要

実装:
- 条件別ROIテーブルを作成
- ROI 80%未満の条件は自動的に賭け金を50%減
```

---

### Phase 2: 「荒れ度」予測フィルターの実装

#### 2.1 1番人気オッズによる自動判定

```python
def classify_race_type(fav1_odds: float) -> str:
    """レースの荒れ度を判定"""
    if fav1_odds <= 1.5:
        return "stable"      # 安定レース（荒れ率3.1%）
    elif fav1_odds <= 3.0:
        return "moderate"    # 中程度（荒れ率15.7%）
    else:
        return "volatile"    # 荒れやすい（荒れ率24.3%）
```

#### 2.2 レースタイプ別の自動戦略選択ロジック

| レースタイプ | 判定条件 | 推奨戦略 | 理由 |
|:-------------|:---------|:---------|:-----|
| **安定レース** | 1番人気≤1.5倍 | 馬単/三連単（2-3着穴狙い） | 1着はほぼ確定、2-3着に穴馬25% |
| **中程度レース** | 1番人気2-3倍 | 穴馬単勝狙い（10-20倍帯） | ROI 80.1%で安定 |
| **荒れやすいレース** | 1番人気≥3倍 | 複勝 or 見送り | 的中率低下、リスクヘッジ優先 |

### Phase 3: 馬単/三連単用の2-3着予測精度向上

#### 3.1 現状の課題

```
現状:
- Top1予測精度: 約20%
- Top2予測精度: 未計測（改善余地あり）
- 馬単ROI: 条件付きで83.7%（1番人気2-3倍帯）

目標:
- 2位予測精度を向上させ、馬単ROIを85%+に
```

#### 3.2 実装アプローチ

```
1. LambdaRankモデルで順位全体を学習
2. 2着・3着向けの専用特徴量を開発:
   - horse_2nd_rate: 過去の2着率
   - horse_close_finish_rate: 僅差フィニッシュ率
   - horse_vs_top_performance: 上位馬との対戦成績
3. 馬単専用モデル（Model B）を構築
```

### Phase 4: 自動戦略切り替えシステム

#### 4.1 システム概要

```
入力: race_id, 1番人気オッズ, 各馬のモデルスコア
```
