## 2. Phase 1: V15 推奨モデルの確立

*詳細は v3.0 レポート参照。ここではサマリーのみ。*

**V15 Fixed** は、過学習を避けるために特徴量を厳選（55個）し、4年間の安定性を確保したベースラインモデルです。単体ROI 76.8% と安定しており、アンサンブルの核となります。

## 3. Phase 2: V22 特徴量エンジニアリング

### 3.1 開発目的
V15の弱点であった「夏場（ROI低下）」と「苦手競馬場（札幌/新潟/阪神）」を克服するため、季節性や会場適性に特化した特徴量を追加。

### 3.2 結果
- **ROI**: 81.3% (V15比 +4.5pt)
- **夏場ROI**: 80.2% (目標達成)
- **リーク対策**: 開発初期に期末統計のリークがあったが、`_is_known_race`フラグによる完全な分離で修正完了。

**結論**: モデルとしては優秀だが、後述の理由によりメインモデル採用は見送り。

## 4. Phase 3: V23/V24 アンサンブル探索と失敗

### 4.1 V23 Hybrid Model (V22 Binary + V15 Residual)
- **狙い**: V22の強力なBinary性能と、V15ベースのResidualを組み合わせる。
- **結果**: **Failure (ROI 77.1%)**
- **原因**: V15 Residual は「V15が見逃した馬」を学習しているため、V22と組み合わせてもシナジーが薄い（V22が見逃す馬とV15が見逃す馬が異なるため）。

### 4.2 V24 Binary Ensemble (V15 + V22)
- **狙い**: 堅実なV15と、特化型のV22をブレンドして安定化。
- **結果**: **Rejection (ROI 79.9%)**
- **原因**: **「多様性の欠如」**。両者とも「堅実な中穴」を狙うモデルであり、相関係数が0.976と高すぎる。ブレンドしてもリスク分散以上のリターンが得られない。

## 6. 再評価: Residual Modelの「宝くじ効果」

なぜ古い **V15 + V4.4 Ensemble** が最強なのか？ その秘密は **Residual Modelの特殊性** にありました。

### 6.1 驚異的なスタッツの違い

| 指標 | V15 / V22 (Binary) | V4.4 (Residual) |
|:---|:---:|:---:|
| **的中率** | ~21% | **3.9%** (極低) |
| **平均オッズ** | ~3.8倍 | **17.9倍** (超高) |
| **役割** | コンスタントに稼ぐ | **宝くじ (一発逆転)** |

Residual Modelは単体では使い物になりません（的中率が低すぎて資金ショートする）。
しかし、Binaryモデルと組み合わせることで**「普段はBinaryで耐え、数ヶ月に一度Residualが大穴を当てて利益を跳ねさせる」**というポートフォリオ効果が生まれています。

V24 (Binary + Binary) にはこの「宝くじ枠」が存在しないため、ROIの上限が頭打ちになります。

## 7. 最終結論と今後の方向性

### 6.1 Action Items

1.  **V15 + V4.4 Ensemble を継続利用する**。
    - Residualのメンテナンス（大穴的中率の監視）を定期的に行う。
2.  **V24 Binary Ensemble は「保険」として保持する**。
    - Residualが完全に機能しなくなった（大穴が全く当たらなくなった）場合の避難先として確保。
3.  **V22特徴量は将来の資産とする**。
    - 次世代モデル開発時に、今回の特化特徴量を標準装備する。

### 6.2 Next Step
単勝ROIの最適化は限界（80%強）に達しました。これ以上の向上は「運」の要素が強くなるため、今後は**券種の多様化（馬連・ワイド・3連系）**による収益機会の拡大にシフトします。
