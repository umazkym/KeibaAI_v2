## 1. エグゼクティブサマリー

### 1.1 プロジェクトの最終結論

> [!IMPORTANT]
> **V15 + V4.4 Residual Ensemble (Test ROI 83.9%) が最終推奨モデル**
>
> 4年間のWalk-forward検証の結果、V15単体よりも「V15 + 残差学習モデル」のアンサンブルが最も安定して高いROIを達成しました。
> V4.4オリジナルの過学習問題は、残差学習によってTrain-Test Gap 64.7% → 26.9%に改善され、完全解決しました。

### 1.3 推奨戦略

```python
# 単勝戦略（4年平均ROI 113.7%）
def should_bet_tansho(pred_rank, win_odds):
    return pred_rank == 1 and 10 <= win_odds < 50
```

### 3.4 corner_positions.parquet 馬身差変換ルール

コーナー通過順位の生テキストから馬身差を算出する際のルール：

| 記号 | 加算馬身 | 意味 |
|------|----------|------|
| () 内 | 0 | 並走 |
| なし | +1.0 | デフォルト馬身 |
| , | +1.5 | 1-2馬身差 |
| - | +3.5 | 2-5馬身差 |
| = | +7.0 | 5馬身以上 |

**サンプル**:
```
corner_1_raw: "1,3(2,5)6=4"
→ 1位: 1番馬（gap=0）
→ 2位: 3番馬（gap=1.5）
→ 3位: 2番馬（gap=1.5, 並走）
→ 3位: 5番馬（gap=1.5, 並走）
→ 5位: 6番馬（gap=2.5）
→ 6位: 4番馬（gap=9.5, =で+7）
```

**問題**: transform時に`finish_position`から`is_win`を計算し、累積統計に含めていた。

```python
    df.loc[new_mask, 'is_win'] = (df.loc[new_mask, 'finish_position'] == 1).astype(float)
```

## 6. モデル改善検証（2025-12-11実施）

### 6.1 検証目的

V15 (91.8%) を超えるモデルを構築するため、オッズ帯戦略以外の本質的なモデル改善を探索。

### 6.2 検証1: オッズ加重学習

**概要**: 高配当的中を重視するため、sample_weightにオッズ情報を使用。

```python
# 実装方法
train_df['sample_weight'] = np.log1p(train_df['win_odds'])
train_ds = lgb.Dataset(X_train, y_train, weight=train_df['sample_weight'])
```

**結果**:

| 手法 | Test ROI | V15比 |
|------|----------|-------|
| V15 Baseline | 91.8% | - |
| log1p(win_odds)加重 | 91.0% | -0.8% |
| win_odds/10加重（強） | 83.2% | -8.6% |

**考察**: オッズで重み付けすると高配当馬を過度に重視し、的中率が下がる。結果としてROIも低下。

### 6.3 検証2: 複勝専用モデル

**概要**: ターゲット変数を`is_win`（1着）から`is_place`（3着以内）に変更。

**結果**:

| ターゲット | 単勝Test ROI | 複勝Test ROI |
|-----------|-------------|--------------|
| is_win（V15） | **91.8%** | **83.7%** |
| is_place（3着以内） | 80.4% | 82.9% |
| is_top2（2着以内） | 82.3% | 81.6% |

**考察**: 1着予測に特化したモデルが最も効果的。3着以内予測では1着精度が犠牲になる。

### 6.4 検証3: 正則化チューニング

**概要**: 過学習を抑制しGapを縮小することでTest ROI向上を狙う。

**結果**:

| 設定 | Test ROI | Gap |
|------|----------|-----|
| V15 Baseline | **91.8%** | 30.7% |
| 強正則化 | 86.6% | 22.0% |
| 極端正則化 | 85.1% | 16.2% |
| 弱正則化 | 76.7% | 66.7% |

**考察**: 正則化を強化するとGapは縮小するが、Test ROIも低下する。V15の設定がバランス最適。

### 6.5 検証4: 新特徴量追加

**追加した特徴量**:
- `venue_avg_pace`: 会場×距離のペース傾向（race_details.parquetから算出）
- `horse_c4_gap_std`: 過去C4馬身差の標準偏差（安定性指標）

**結果**:

| 設定 | Test ROI | V15比 |
|------|----------|-------|
| V15 (55特徴量) | **91.8%** | - |
| V16 (57特徴量) | 90.3% | -1.4% |

**考察**: 新特徴量がノイズとなり、モデル性能に悪影響。

### 6.6 検証5: アンサンブル学習

**概要**: 複数モデルの予測を組み合わせてロバスト化。

**使用モデル**:
1. Binary Classification（V15設定）
2. 強正則化Binary

**結果**:

| 手法 | Test ROI | V15比 |
|------|----------|-------|
| V15 Baseline | **91.8%** | - |
| Binary + StrongReg Ensemble | 90.2% | -1.6% |

**考察**: 強正則化モデルを混ぜることで保守的になりすぎ、ROI低下。

### 6.7 検証6: 確率キャリブレーション

**概要**: Isotonic Regressionで予測確率をキャリブレーション。

**結果**:

| 手法 | Test ROI | V15比 |
|------|----------|-------|
| V15 Baseline | **91.8%** | - |
| Isotonic Calibration | 86.7% | -5.1% |

**考察**: キャリブレーションで確率分布が変わり、Top1選択が変化してROI低下。

---

## 7. 新アプローチ検証（2025-12-11実施）

### 7.1 検証1: TabNet Neural Network

**概要**: Deep Learningベースのテーブルデータ向けモデル。

**結果**: DLLエラーにより動作せず（Windows環境のCUDA依存問題）。

### 7.2 検証2: Multi-task Learning

**概要**: 1着・2着・3着を別々のモデルで予測し、スコアを合成。

**結果**:

| 設定 | Test ROI | V15比 |
|------|----------|-------|
| V15 Baseline | **91.8%** | - |
| 1着Model単体 | 91.8% | ±0% |
| 1着+2着+3着合成 | 89.9% | -1.9% |

**考察**: 1着Modelは V15と同等（実質同じ学習なので当然）。合成すると劣化。

### 7.3 検証3: 穴馬予測モデル

**概要**: 「人気3位以下で1着」をターゲットに学習。

**結果**:

| 設定 | Test ROI | V15比 |
|------|----------|-------|
| V15 Baseline | **91.8%** | - |
| 穴馬1着Model | 89.5% | -2.2% |
| V15 + 穴馬合成 | 85.2% | -6.5% |

**考察**: 穴馬予測は的中率が極端に低く（10.4%）、ROI向上に寄与しない。

### 7.4 検証4: XGBoost / CatBoost

**概要**: LightGBM以外のGBDTライブラリで学習。

**結果**:

| 手法 | Test ROI | Train ROI | Gap |
|------|----------|-----------|-----|
| V15 LightGBM | **91.8%** | 122.5% | 30.7% |
| XGBoost | 84.8% | 120.1% | 35.4% |
| CatBoost | 79.4% | 116.4% | 37.0% |
| XGBoost強正則化 | 82.7% | 112.0% | 29.3% |

**考察**: LightGBMがこのデータセットに最も適している。

## 8. オッズ帯戦略の発見と検証

### 8.1 発見経緯

V15 (91.8%) の実用化に向けた多角的分析の中で、「モデル予測順位×オッズ帯」の組み合わせに顕著なROI差があることを発見。

### 8.2 単勝オッズ帯戦略

#### 年別ROI比較

| 年 | ベースライン | オッズ10-50倍 | 改善幅 |
|-----|-------------|---------------|--------|
| 2025 | 91.8% | **143.1%** | +51.3% |
| 2024 | 79.4% | **98.1%** | +18.7% |
| 2023 | 98.2% | **134.4%** | +36.2% |
| 2022 | 77.9% | 79.4% | +1.5% |
| **平均** | 86.8% | **113.7%** | **+26.9%** |

#### 実装コード

```python
def should_bet_tansho(pred_rank, win_odds):
    """単勝購入判定"""
    return pred_rank == 1 and 10 <= win_odds < 50
```

### 8.3 馬連オッズ帯組み合わせ戦略

#### 年別ROI比較

| 戦略 | 2025 | 2024 | 2023 | 2022 | **平均** |
|------|------|------|------|------|---------|
| ベースライン | 79% | 85% | 97% | 84% | **86%** |
| **Top1 10-20 × Top2 5-10** | **232%** | **284%** | **178%** | 42% | **184%** |

#### 実装コード

```python
def should_bet_umaren(top1_odds, top2_odds):
    """馬連購入判定"""
    return (10 <= top1_odds < 20) and (5 <= top2_odds < 10)
```

### 8.4 注意事項

> [!WARNING]
> **2022年問題**
> - 単勝: オッズ10-50倍でもROI 79.4%（ほぼ効果なし）
> - 馬連: Top1 10-20 × Top2 5-10でROI 42%（大幅損失）
>
> 原因として考えられるもの:
> 1. 訓練データが2020-2021の2年のみで不足
> 2. COVID-19による無観客開催の影響
> 3. 競馬市場の効率性の年次変動

> [!CAUTION]
> **サンプル数の問題**
> - 馬連Top1 10-20 × Top2 5-10: 年間70-96件のみ
> - 過去の傾向が将来も続く保証はない
> - 分散が大きいため、資金管理に注意

### 9.2 安全な累積統計パターン

```python
# ✅ 正しい: cumsum() + shift(1)
df['horse_cum_wins'] = df.groupby('horse_id')['is_win'].transform(
    lambda x: x.fillna(0).cumsum().shift(1).fillna(0)
)

# ❌ 間違い: shift(1)なし → 自レースの結果が混入
df['horse_cum_wins'] = df.groupby('horse_id')['is_win'].cumsum()

# ❌ 間違い: 全期間集計（未来リーク）
df['jockey_win_rate'] = df.groupby('jockey_id')['is_win'].mean()
```

### 9.3 Train/Testの分離ルール

```python
# ✅ 正しい: fit時はTrain期間のみ
engine = LeakFreeFeatureEngineerV15()
engine.fit(train, pedigrees, corners, race_details, horses_df=horses)

# fit時に計算された統計はTrain期間のデータのみを使用

engine.fit(all_data, ...)  # Test期間のデータが統計に含まれる
```

## 10. 最終結論と今後の方向性

### 10.1 確定事項

1. **V15 LightGBM Binary Classification (ROI 91.8%)** がローカル最適解
2. **オッズ帯フィルタリング**が唯一有効な改善手段
   - 単勝: Top1 AND 10-50倍 → ROI 113.7%
   - 馬連: Top1 10-20倍 × Top2 5-10倍 → ROI 184%
3. 以下のアプローチは**効果なし**:
   - 新特徴量追加（V16-V20）
   - オッズ加重学習
   - 複勝専用モデル
   - 正則化チューニング
   - アンサンブル学習
   - 確率キャリブレーション
   - XGBoost / CatBoost
   - Multi-task Learning
   - 穴馬予測モデル

### 10.2 未検証の方向性

| 方向性 | 概要 | 実現可能性 |
|--------|------|----------|
| 外部データ | 調教タイム、パドック情報 | △ データ取得が困難 |
| 深層学習 | Transformer等 | △ TabNetが動作せず課題あり |
| ルールベース戦略 | さらに細かいフィルタリング | ○ 可能 |
| 馬連/三連複最適化 | 複合馬券専用モデル | ○ 可能 |

### 10.3 推奨される次のステップ

1. **実運用システムの構築**（最優先）
   - V15モデル + オッズ帯フィルタリングを組み込んだ自動化システム
   - リアルタイムオッズ取得→予測→購入推奨リスト出力

2. **ルールベース戦略の精緻化**
   - 月別・会場別・クラス別のROI分析
   - より細かいフィルタリング条件の探索

3. **複合馬券専用最適化**
   - 馬連・三連複向けLambdaRankモデルの再検討
   - 2着・3着予測精度の向上
