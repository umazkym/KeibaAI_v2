> [!IMPORTANT]
> **ディレクトリ配置ルール**（2025-11-24 標準化完了）:
> - **`keibaai/src/`**: Pythonパッケージとして `import` されるモジュール・ライブラリ**のみ**。実行スクリプトは含まない。
> - **`scripts/`**: CLIから直接実行するスクリプト（エントリーポイント）。全て `python scripts/xxx/yyy.py` で実行。
> - **`docs/`**: プロジェクトドキュメント。レポートは `docs/reports/` に集約。
> - **`archive/`**: 使用されなくなった古いスクリプト・ログ。

**ディレクトリ配置の原則**:
- **モジュール vs スクリプト**: `keibaai/src/` は `import` 可能なクラス・関数のみ。`scripts/` は `python scripts/xxx.py` で実行。
- **実験的コード**: `scripts/training/experimental/` に保存し、後から分析・参照可能に。
- **単一ルール**: 例外なく一貫した配置。新規スクリプトは必ず `scripts/` に配置。

def parse_results_html(file_path, race_id=None) -> pd.DataFrame:
    # 1. ファイル読み込み（EUC-JP デコード）
    html_bytes = read_binary_file(file_path)
    html_text = html_bytes.decode('euc_jp', errors='replace')

    # 2. BeautifulSoupでパース
    soup = BeautifulSoup(html_text, 'html.parser')

    # 3. レースメタデータ抽出（4段階フォールバック）
    race_metadata = extract_race_metadata_enhanced(soup)
    # - distance_m, track_surface, weather, track_condition
    # - venue, day_of_meeting, round_of_year
    # - race_class, age_restriction

    # 4. 結果テーブル抽出
    result_table = soup.find('table', class_='race_table_01')

    # 5. 各行をパース
    for tr in result_table.find_all('tr'):
        row_data = parse_result_row_enhanced(tr, race_id, ...)
        # - finish_position, bracket_number, horse_number
        # - horse_id, horse_name, sex, age
        # - jockey_id, jockey_name
        # - trainer_id, trainer_name, owner_name
        # - finish_time_seconds, margin_seconds
        # - passing_order_{1,2,3,4}
        # - last_3f_time, win_odds, popularity
        # - horse_weight, horse_weight_change

    # 6. DataFrame化 + 派生特徴量
    df = pd.DataFrame(rows)
    df = add_derived_features(df)
    # - pace_index, position_change_*
    # - popularity_finish_diff, relative_odds

    return df
```

**特徴量カテゴリ**:
```
[1] レース特徴（Race Features）
    - distance_m, track_surface, weather, track_condition
    - venue, race_class, age_restriction
    - head_count, prize_1st

[2] 馬特徴（Horse Features）
    - age, sex, horse_weight, horse_weight_change
    - avg_finish_last3, avg_finish_last5, avg_finish_last10
    - win_rate_last10, place_rate_last10
    - days_since_last_race（休養期間）
    - weight_trend（体重推移トレンド）

[3] 騎手特徴（Jockey Features）
    - jockey_win_rate, jockey_place_rate
    - jockey_roi（投資回収率）
    - jockey_avg_odds
    - jockey_venue_win_rate（競馬場別成績）

[4] 調教師特徴（Trainer Features）
    - trainer_win_rate, trainer_place_rate
    - trainer_roi
    - stable_size（厩舎規模）

[5] 血統特徴（Pedigree Features）
    - sire_id, dam_id, damsire_id（エンコード済み）
    - sire_avg_finish（父系平均着順）
    - dam_avg_finish（母系平均着順）

[6] 派生特徴（Derived Features）
    - pace_index = time_except_last3f / last_3f_time
    - position_change_* = passing_order_{i+1} - passing_order_{i}
    - popularity_finish_diff = finish_position - popularity
    - relative_odds = win_odds / レース平均オッズ
```

        モンテカルロシミュレーション

        Args:
            mu_array: 各馬の期待完走時間 [N]
            sigma_array: 各馬の標準偏差 [N]
            nu: レース全体の自由度
            K: シミュレーション回数

        Returns:
            win_probs: 各馬の勝率 [N]
        """
        N = len(mu_array)
        win_counts = np.zeros(N)

        for k in range(K):
            # 各馬の完走時間をt分布からサンプリング
            finish_times = np.array([
                stats.t.rvs(df=nu, loc=mu_i, scale=sigma_i)
                for mu_i, sigma_i in zip(mu_array, sigma_array)
            ])

            # 着順を決定
            finish_order = np.argsort(finish_times)
            winner_idx = finish_order[0]
            win_counts[winner_idx] += 1

        win_probs = win_counts / K
        return win_probs
```

### 6. Optimizer（ポートフォリオ最適化）

**場所**: `keibaai/src/modules/optimizer/`

**Kelly基準実装**:
```python
from scipy.optimize import minimize

class PortfolioOptimizer:
    def optimize_kelly(
        self,
        win_probs: np.ndarray,
        odds: np.ndarray,
        capital: float,
        kelly_fraction: float = 0.25
    ) -> np.ndarray:
        """
        Fractional Kelly Criterion

        目的関数:
            maximize Σ f_i * log(1 + (o_i - 1) * f_i / W_0)

        制約:
            Σ f_i ≤ W_0
            f_i ≥ 0
            EV_i = p_i * o_i - 1 > threshold
        """
        N = len(win_probs)

        # 目的関数（負にして最小化問題に変換）
        def objective(f):
            return -np.sum(
                f * np.log(1 + (odds - 1) * f / capital)
            )

        # 制約条件
        constraints = [
            {'type': 'ineq', 'fun': lambda f: capital - np.sum(f)},  # 資本制約
            *[{'type': 'ineq', 'fun': lambda f, i=i: f[i]}  # 非負制約
              for i in range(N)]
        ]

        # 期待値フィルタ
        ev = win_probs * odds - 1
        initial_guess = np.where(ev > 0.05, capital * 0.05, 0)

        # 最適化実行
        result = minimize(
            objective,
            initial_guess,
            constraints=constraints,
            method='SLSQP'
        )

        # Kelly fractionでリスク調整
        optimal_bets = result.x * kelly_fraction

        return optimal_bets
```

## 🎨 設計原則

### 1. 疎結合（Loose Coupling）

各モジュールはParquetファイルを介して通信：
```python
# ❌ 密結合
parser_result = parse_html(html)
features = generate_features(parser_result)

# ✅ 疎結合
parse_html(html, output_path='races.parquet')
features = generate_features(input_path='races.parquet')
```

### 2. 単一責任原則（SRP）

各モジュールは1つの責務のみ：
- Preparing = データ取得
- Parsers = データ構造化
- Features = 特徴量生成
- Models = モデル訓練

### 3. 型安全性

Pandas nullable integersの使用：
```python
# ❌ float64で整数表現（欠損値対応だがメモリ無駄）
df['finish_position'] = df['finish_position'].astype('float64')

# ✅ nullable integer
df['finish_position'] = df['finish_position'].astype('Int64')
```

### 4. 冪等性（Idempotence）

同じ入力に対して何度実行しても同じ結果：
```python
# パース処理は何度実行しても同じParquetファイルを生成
parse_results_html('202310010811.bin')  # → races.parquet
```

### 5. テスタビリティ

全モジュールがunit test可能：
```python
# tests/unit/test_parsers.py
def test_parse_time_to_seconds():
    assert parse_time_to_seconds("1:23.4") == 83.4
    assert parse_time_to_seconds("59.8") == 59.8
```
