```python
# ❌ NG: float64で整数を表現
df['finish_position'] = df['finish_position'].astype('float64')

df['finish_position'] = df['finish_position'].astype('Int64')
```

## 🗂️ パーティショニング戦略

### features.parquet のパーティション

```
data/features/parquet/
├── year=2020/
│   ├── month=01/
│   │   └── features.parquet
│   ├── month=02/
│   │   └── features.parquet
│   └── ...
├── year=2021/
│   ├── month=01/
│   └── ...
└── year=2023/
    ├── month=01/
    ├── month=02/
    └── month=10/
        └── features.parquet
```

**メリット**:
1. 期間フィルタリングが高速
2. 増分更新が容易
3. メモリ使用量削減

**読み込み例**:
```python
import pyarrow.parquet as pq

# 2023年10月のデータのみ読み込み
table = pq.read_table(
    'data/features/parquet/',
    filters=[
        ('year', '=', 2023),
        ('month', '=', 10)
    ]
)
df = table.to_pandas()
```

## ✅ データ品質ルール

### 1. NOT NULL制約

| カラム | 理由 |
|-------|------|
| race_id | 主キー |
| horse_number | 主キー |
| race_date | 時系列分析に必須 |

### 2. 範囲制約

```python
# 着順: 1〜出走頭数
assert 1 <= finish_position <= head_count

# 馬番: 1〜18（通常は1〜16）
assert 1 <= horse_number <= 18

# 年齢: 2〜10（通常は2〜7）
assert 2 <= age <= 10

# 距離: 800〜4000m
assert 800 <= distance_m <= 4000
```

### 3. 外れ値検出

```python
# タイムの3σチェック
mean_time = df.groupby(['distance_m', 'track_surface'])['finish_time_seconds'].mean()
std_time = df.groupby(['distance_m', 'track_surface'])['finish_time_seconds'].std()

outlier_mask = (
    (df['finish_time_seconds'] < mean_time - 3 * std_time) |
    (df['finish_time_seconds'] > mean_time + 3 * std_time)
)

df.loc[outlier_mask, 'time_outlier_flag'] = True
```

### 4. 参照整合性

```python
# races.horse_id は horses.horse_id に存在すること
assert df['horse_id'].isin(horses_df['horse_id']).all()

# races.race_id は shutuba.race_id に存在すること
assert df['race_id'].isin(shutuba_df['race_id']).all()
```

### 5. 論理整合性

```python
# 人気と着順の差が極端でないこと（±10以内）
assert abs(df['popularity_finish_diff']).max() <= 10

# 馬体重が常識的な範囲（300kg〜600kg）
assert 300 <= df['horse_weight'] <= 600
```
