## 🌐 スクレイピング概要

### データソース

| サイト | 取得データ | 方法 | 頻度 |
|-------|----------|------|------|
| **netkeiba.com** | レース結果、出馬表、馬データ、血統 | requests + BeautifulSoup | 日次 |
| **JRA公式** | リアルタイムオッズ | Selenium | レース直前 |

### 取得プロセス

```
【Phase 0-1】 開催日程の取得
netkeiba.com/top/calendar.html
    ↓
kaisai_dates.csv (開催日リスト)

【Phase 0-2】 レースIDリストの取得
netkeiba.com/race/list/{race_date}/
    ↓
race_id_list.csv (1日あたり50-100レース)

【Phase 0-3】 レース結果HTMLの取得
FOR EACH race_id:
    netkeiba.com/race/{race_id}/
    ↓
    data/raw/html/race/{race_id}.bin

【Phase 0-4】 出馬表HTMLの取得
FOR EACH race_id:
    netkeiba.com/race/shutuba.html?race_id={race_id}
    ↓
    data/raw/html/shutuba/{race_id}.bin

【Phase 0-5】 馬IDリストの抽出
FROM races.parquet:
    SELECT DISTINCT horse_id
    ↓
horse_id_list.txt

【Phase 0-6】 馬プロフィールHTMLの取得
FOR EACH horse_id:
    netkeiba.com/horse/{horse_id}/
    ↓
    data/raw/html/horse/{horse_id}_profile.bin

【Phase 0-7】 馬過去成績HTMLの取得
FOR EACH horse_id:
    check TTL (default 7 days)
    if expired OR not exists:
        netkeiba.com/horse/ped/{horse_id}/
        ↓
        data/raw/html/horse/{horse_id}_perf.bin

【Phase 0-8】 血統HTMLの取得
FOR EACH horse_id:
    netkeiba.com/horse/ped/{horse_id}/
    ↓
    data/raw/html/ped/{horse_id}.bin
```

## 🎯 対象サイトと取得データ

### netkeiba.com

#### 1. レース結果ページ

**URL形式**: `https://db.netkeiba.com/race/{race_id}/`

**例**: `https://db.netkeiba.com/race/202310010811/`

**取得データ**:
- レースメタデータ（距離、馬場、天候、競馬場）
- 結果テーブル（着順、馬名、騎手、タイム、オッズ）
- 払戻金情報（単勝、複勝、馬連、馬単、ワイド）

**HTML構造**:
```html
<div class="data_intro">
    <div class="diary_snap_cut">

</div>

<table class="race_table_01">
    <tbody>
        <tr>
            <td>1</td>                    <!-- 着順 -->

            <td><a href="/jockey/01234/">福永祐一</a></td>
```

#### 2. 出馬表ページ

**URL形式**: `https://race.netkeiba.com/race/shutuba.html?race_id={race_id}`

**取得データ**:
- 出走馬リスト
- 朝オッズ、朝人気
- ブリンカー、予想印

#### 3. 馬プロフィールページ

**URL形式**: `https://db.netkeiba.com/horse/{horse_id}/`

**取得データ**:
- 生年月日、性別、毛色
- 調教師、馬主、生産者
- 馬体情報（体高、胸囲、管囲）

#### 4. 馬過去成績ページ

**URL形式**: `https://db.netkeiba.com/horse/result/{horse_id}/`

**取得データ**:
- 全レース履歴
- 各レースの詳細（着順、タイム、オッズ）

#### 5. 血統ページ

**URL形式**: `https://db.netkeiba.com/horse/ped/{horse_id}/`

**取得データ**:
- 5世代血統表
- 各先祖馬の生年、毛色

### 6. キャッシング戦略

#### レースIDキャッシング

```python
import json
from pathlib import Path

RACE_ID_CACHE_PATH = Path("keibaai/data/master/race_id_cache.json")

def load_race_id_cache() -> Dict[str, List[str]]:
    """キャッシュからレースIDを読み込み"""
    if RACE_ID_CACHE_PATH.exists():
        with open(RACE_ID_CACHE_PATH, 'r', encoding='utf-8') as f:
            return json.load(f)
    return {}

def save_race_id_cache(cache: Dict[str, List[str]]):
    """レースIDをキャッシュに保存"""
    RACE_ID_CACHE_PATH.parent.mkdir(parents=True, exist_ok=True)
    with open(RACE_ID_CACHE_PATH, 'w', encoding='utf-8') as f:
        json.dump(cache, f, ensure_ascii=False, indent=2)

def scrape_race_id_list(kaisai_date: str) -> List[str]:
    """レースIDリスト取得（キャッシュ優先）"""
    cache = load_race_id_cache()
    
    # キャッシュヒット
    if kaisai_date in cache:
        logger.info(f"Cache hit: {kaisai_date}")
        return cache[kaisai_date]
    
    # キャッシュミス → Seleniumで取得
    logger.info(f"Cache miss: {kaisai_date}, fetching...")
    race_ids = _fetch_race_ids_selenium(kaisai_date)
    
    # キャッシュに保存
    cache[kaisai_date] = race_ids
    save_race_id_cache(cache)
    
    return race_ids
```

**メリット**:
- 同じ日付の再実行時にSeleniumを起動せず、即座にレースIDを取得
- 過去データの分析時に大幅な時間短縮

```python
CALENDAR_CACHE_PATH = Path("keibaai/data/master/calendar_cache.json")

def scrape_kaisai_date(start_date: str, end_date: str) -> List[str]:
    """開催日取得（月単位でキャッシュ）"""
    cache = load_calendar_cache()
    
    all_dates = []
    current = datetime.strptime(start_date, '%Y-%m-%d')
    end = datetime.strptime(end_date, '%Y-%m-%d')
    
    while current <= end:
        month_key = current.strftime('%Y-%m')
        
        # キャッシュチェック（過去月のみ）
        if month_key in cache and current < datetime.now().replace(day=1):
            logger.info(f"Using cached calendar: {month_key}")
            all_dates.extend(cache[month_key])
        else:
            # Web取得
            month_dates = _fetch_calendar_web(current.year, current.month)
            cache[month_key] = month_dates
            all_dates.extend(month_dates)
        
        current = current.replace(day=1) + timedelta(days=32)
        current = current.replace(day=1)
    
    save_calendar_cache(cache)
    return all_dates
```

**メリット**:
- 過去月のデータは一度取得すれば永続的にキャッシュ利用
- サーバー負荷の軽減

### メインスクレイパー (src/preparing/_scrape_html.py)

```python
def fetch_html_robust_get(
    url: str,
    session: Optional[requests.Session] = None,
    additional_headers: Optional[Dict[str, str]] = None
) -> Optional[bytes]:
    """
    堅牢なHTML取得（requestsベース）

    Returns:
        HTML content (bytes) or None if failed
    """
    if session is None:
        session = get_robust_session()

    try:
        # ランダムスリープ
        sleep_time = random.uniform(MIN_SLEEP_SECONDS, MAX_SLEEP_SECONDS)
        time.sleep(sleep_time)

        # リクエスト実行
        headers = {"User-Agent": random.choice(USER_AGENTS)}
        if additional_headers:
            headers.update(additional_headers)

        response = session.get(url, headers=headers, timeout=30)

        # HTTP 400対策
        if response.status_code == 400:
            logger.critical(f"HTTP 400: {url}")
            time.sleep(60)
            return None

        response.raise_for_status()
        return response.content

    except requests.exceptions.RequestException as e:
        logger.error(f"Request failed: {url}, {e}")
        return None
```

### 血統ページの取得（requestsベース）

**変更理由**: 以前はSeleniumを使用していましたが、頻繁なタイムアウトとドライバー再起動が発生していたため、`requests`に切り替えました。

```python
def scrape_html_ped(
    horse_id_list: List[str],
    output_dir: Path,
    session: Optional[requests.Session] = None
):
    """血統HTMLの取得（requestsベース）"""
    
    if session is None:
        session = get_robust_session()
    
    output_dir.mkdir(parents=True, exist_ok=True)
    
    for horse_id in tqdm(horse_id_list, desc="Fetching pedigree"):
        output_file = output_dir / f"{horse_id}.bin"
        
        if output_file.exists():
            continue
        
        url = f"https://db.netkeiba.com/horse/ped/{horse_id}/"
        html_bytes = fetch_html_robust_get(url, session)
        
        if html_bytes:
            with open(output_file, 'wb') as f:
                f.write(html_bytes)
            logger.info(f"Saved: {output_file}")
```

**効果**:
- 取得速度が大幅に向上（Seleniumと比較して約3-5倍高速）
- タイムアウトエラーが激減
- メモリ使用量の削減

### レース結果のバッチスクレイピング

```python
def scrape_race_results(
    race_id_list: List[str],
    output_dir: Path,
    session: Optional[requests.Session] = None
):
    """レース結果のバッチスクレイピング"""

    if session is None:
        session = get_robust_session()

    output_dir.mkdir(parents=True, exist_ok=True)

    success_count = 0
    fail_count = 0

    for race_id in tqdm(race_id_list, desc="Scraping race results"):
        output_file = output_dir / f"{race_id}.bin"

        # 既にダウンロード済みならスキップ
        if output_file.exists():
            logger.info(f"Already exists: {race_id}")
            continue

        # URL構築
        url = f"https://db.netkeiba.com/race/{race_id}/"

        # HTML取得
        html_bytes = fetch_html_robust_get(url, session)

        if html_bytes:
            # EUC-JPバイナリとして保存
            with open(output_file, 'wb') as f:
                f.write(html_bytes)
            success_count += 1
        else:
            fail_count += 1
            logger.warning(f"Failed to scrape: {race_id}")

    logger.info(f"Scraping complete: {success_count} success, {fail_count} failed")
```

### JRAオッズ取得（Selenium）

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

def scrape_jra_odds(race_id: str) -> Dict:
    """
    JRAリアルタイムオッズ取得
    """
    driver = webdriver.Chrome()

    try:
        # JRA ODDS画面へ
        url = f"https://www.jra.go.jp/JRADB/accessO.html"
        driver.get(url)

        # レース選択（JavaScript操作）
        wait = WebDriverWait(driver, 30)
        race_select = wait.until(
            EC.presence_of_element_located((By.ID, "raceSelect"))
        )
        race_select.send_keys(race_id)

        # オッズテーブル待機
        odds_table = wait.until(
            EC.presence_of_element_located((By.CLASS_NAME, "oddsTable"))
        )

        # パース
        rows = odds_table.find_elements(By.TAG_NAME, "tr")
        odds_data = {}

        for row in rows:
            cells = row.find_elements(By.TAG_NAME, "td")
            if len(cells) >= 3:
                horse_number = cells[0].text
                win_odds = cells[1].text
                place_odds = cells[2].text

                odds_data[horse_number] = {
                    'win_odds': float(win_odds),
                    'place_odds': place_odds
                }

        return odds_data

    finally:
        driver.quit()
```
