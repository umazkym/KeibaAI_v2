## 🎲 モンテカルロシミュレーション

### 目的

μ, σ, νから**各馬の勝率**を推定

### アルゴリズム

```python
for k = 1 to K (K=1000):
    for horse_i in race:
        # t分布からサンプリング
        time_i_k ~ t_ν(μ_i, σ_i²)

    # 着順決定
    finish_order = argsort(times)

    # 勝者記録
    winner_counts[finish_order[0]] += 1

# 勝率推定
P(win) = winner_counts / K
```

### 実装（RaceSimulator）

**ファイル**: `keibaai/src/modules/sim/simulator.py`

```python
import numpy as np
from scipy.stats import t

class RaceSimulator:
    def __init__(self, K=1000):
        """
        Args:
            K: シミュレーション回数
        """
        self.K = K

    def simulate(
        self,
        mu_array: np.ndarray,
        sigma_array: np.ndarray,
        nu: float
    ) -> dict:
        """
        モンテカルロシミュレーション

        Args:
            mu_array: 各馬の期待完走時間 [N]
            sigma_array: 各馬の標準偏差 [N]
            nu: レース全体の自由度

        Returns:
            dict: {
                'win_probs': [N],
                'place_probs': [N],
                'show_probs': [N]
            }
        """
        N = len(mu_array)
        win_counts = np.zeros(N)
        place_counts = np.zeros(N)  # 2着以内
        show_counts = np.zeros(N)   # 3着以内

        for k in range(self.K):
            # 各馬の完走時間サンプリング
            finish_times = np.array([
                t.rvs(df=nu, loc=mu_i, scale=sigma_i)
                for mu_i, sigma_i in zip(mu_array, sigma_array)
            ])

            # 着順決定
            finish_order = np.argsort(finish_times)

            # カウント
            win_counts[finish_order[0]] += 1
            place_counts[finish_order[:2]] += 1
            show_counts[finish_order[:3]] += 1

        # 確率推定
        win_probs = win_counts / self.K
        place_probs = place_counts / self.K
        show_probs = show_counts / self.K

        return {
            'win_probs': win_probs,
            'place_probs': place_probs,
            'show_probs': show_probs
        }
```

### 高速化版（NumPyベクトル化）

```python
def simulate_vectorized(
    self,
    mu_array: np.ndarray,
    sigma_array: np.ndarray,
    nu: float
) -> dict:
    """ベクトル化版（10-20x高速）"""

    N = len(mu_array)

    # 一度に全サンプル生成 [K x N]
    finish_times_all = np.array([
        t.rvs(df=nu, loc=mu_array, scale=sigma_array, size=self.K)
        for _ in range(N)
    ]).T

    # 着順決定 [K x N]
    finish_orders = np.argsort(finish_times_all, axis=1)

    # カウント
    win_counts = np.bincount(finish_orders[:, 0], minlength=N)
    place_counts = np.bincount(finish_orders[:, :2].flatten(), minlength=N)
    show_counts = np.bincount(finish_orders[:, :3].flatten(), minlength=N)

    win_probs = win_counts / self.K
    place_probs = place_counts / self.K
    show_probs = show_counts / self.K

    return {
        'win_probs': win_probs,
        'place_probs': place_probs,
        'show_probs': show_probs
    }
```

## 💰 ポートフォリオ最適化

### Kelly Criterion（ケリー基準）

**発明者**: John L. Kelly Jr. (1956)

**基本公式**:
```
f* = (p * (o - 1) - (1 - p)) / (o - 1)

where:
  f*: 資産の何割を賭けるか
  p:  勝率
  o:  オッズ
```

**例**:
```python
p = 0.35  # 35%の勝率
o = 3.2   # 3.2倍のオッズ

f_star = (0.35 * (3.2 - 1) - (1 - 0.35)) / (3.2 - 1)
       = (0.35 * 2.2 - 0.65) / 2.2
       = (0.77 - 0.65) / 2.2
       = 0.055  # → 資産の5.5%を賭ける
```

### Fractional Kelly（リスク調整版）

**問題**: Full Kellyは積極的すぎる → ドローダウンが大きい

**解決**: Kelly fractionで縮小

```python
f_actual = f_star * kelly_fraction

# kelly_fraction の推奨値:
# 0.25: 保守的（推奨）
# 0.50: 標準
# 1.00: フルケリー（リスク大）
```

### Multi-Horse Portfolio Optimization

**最適化問題**:
```
Maximize: Σ f_i * log(1 + (o_i - 1) * f_i / W_0)

Subject to:
  Σ f_i ≤ W_0          # 資本制約
  f_i ≥ 0              # 非負制約
  EV_i > threshold     # 期待値フィルタ

where:
  f_i: 馬iへの賭け金
  o_i: 馬iのオッズ
  W_0: 総資本
  EV_i = p_i * o_i - 1  # 期待値
```

### 2段階投資ロジック (Two-Stage Betting Logic)

**目的**: 1日の総予算を効率的に配分しつつ、直前オッズの変化に対応する。

**フェーズ1: 朝一の予算配分 (Morning Allocation)**
*   **タイミング**: 当日朝（または前日夜）
*   **入力**: 全レースのシミュレーション結果、朝一オッズ（または確定オッズ）
*   **ロジック**:
    *   各レースの「魅力度（スコア）」を計算（例: Kelly基準での期待成長率の総和）。
    *   1日の総予算（例: 1万円）を、スコアに応じて比例配分する。
    *   期待値が低いレースには予算を割り当てない（0円）。
*   **担当**: `DailyAllocator`

**フェーズ2: レース直前の投資実行 (Just-Before-Race Execution)**
*   **タイミング**: 各レース発走直前（例: 5分前）
*   **入力**: そのレースのシミュレーション結果、**直前オッズ**、配分されたレース予算
*   **ロジック**:
    *   配分された予算内で、Fractional Kelly Criterionを用いて最適な買い目を決定。
    *   直前オッズで期待値が閾値を下回った場合は、投資を見送る（スキップ）。
*   **担当**: `PortfolioOptimizer`

### 並列化（複数レース）

```python
from multiprocessing import Pool

def simulate_single_race(args):
    race_id, mu, sigma, nu = args
    simulator = RaceSimulator(K=1000)
    return race_id, simulator.simulate(mu, sigma, nu)

# 並列実行
with Pool(processes=4) as pool:
    results = pool.map(simulate_single_race, race_args_list)
```

### キャッシング

```python
from functools import lru_cache

@lru_cache(maxsize=100)
def simulate_cached(mu_tuple, sigma_tuple, nu, K):
    """タプルは hashable なのでキャッシュ可能"""
    mu = np.array(mu_tuple)
    sigma = np.array(sigma_tuple)
    simulator = RaceSimulator(K)
    return simulator.simulate(mu, sigma, nu)
```
