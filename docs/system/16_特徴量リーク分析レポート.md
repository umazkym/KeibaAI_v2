## 2. リークのメカニズム

### 問題のあるコード例（condition_features.py）

```python
# ❌ リークあり: 全期間のデータを集計
jockey_dist_stats = performance_df.groupby(
    ['jockey_id', 'distance_category']
).agg({
    'is_win': 'mean'  # テスト期間の結果も含まれる
})
```

### なぜこれがリークなのか

```
時系列: ---[Train期間]---[Valid期間]---[Test期間]---

全期間集計の問題:
- 2024年1月のレースを予測する際に、
  2024年2月〜12月の結果も使用されている
- これは「未来の情報」を使った予測
```

---

## 3. リーク対応策

### 対応A: expanding().mean().shift(1) で再計算

**適用対象**: 騎手勝率、調教師勝率

```python
# ✅ リークフリー: 当該レース前までの累積のみ
perf = perf.sort_values(['race_date', 'race_id'])
perf['jockey_win_rate_lf'] = perf.groupby('jockey_id')['is_win'].transform(
    lambda x: x.expanding().mean().shift(1)
)
```

**メリット**:
- 特徴量の価値を保持しつつリーク回避
- 時系列を正しく反映

**対応した特徴量**:
- `jockey_win_rate_lf`
- `trainer_win_rate_lf`
- `jockey_venue_win_rate_lf`
- `jockey_surface_win_rate_lf`

### 対応B: Train期間の統計を固定使用

**適用対象**: 血統関連（父、母父など）

```python
# ✅ リークフリー: Train期間のみで計算、固定使用
train_cutoff = pd.Timestamp('2023-01-01')
train_perf = perf[perf['race_date'] < train_cutoff]

sire_stats = train_perf.groupby('sire_id').agg({
    'is_win': 'mean'
})
# この統計をValid/Testにも適用
```

**理論的根拠**:
- 血統の傾向は短期間では変化しない
- 父馬が変わることはない
- 10年単位で見ても大きな変動は少ない

**対応した特徴量**:
- `sire_win_rate_fixed`
- `gap_sire_pop_fixed`

### 対応C: 除外（修正コストが高い場合）

**適用対象**: コンボ特徴量、細かい条件別勝率

```python
LEAK_PATTERNS = [
    'combo_win_rate', 'combo_avg_finish',
    'nicks_win_rate', 'nicks_avg_finish',
    ...
]
features = [f for f in features if f not in LEAK_PATTERNS]
```

## 5. 今後の注意点

### 新しい特徴量を追加する際のチェックリスト

1. [ ] `groupby().mean()`を使用していないか
2. [ ] 集計範囲は「当該レース前」のみか
3. [ ] `shift(1)`で時系列シフトしているか
4. [ ] 着順（`finish_position`）を直接参照していないか
5. [ ] オッズ（`win_odds`）を予測対象と関連付けていないか

### 安全な特徴量パターン

```python
# ✅ 安全: 過去N走の統計（shift済み）
df['past_5_finish_mean'] = df.groupby('horse_id')['finish_position'].transform(
    lambda x: x.shift(1).rolling(5).mean()
)

# ✅ 安全: 累積統計（shift済み）
df['jockey_win_rate_lf'] = df.groupby('jockey_id')['is_win'].transform(
    lambda x: x.expanding().mean().shift(1)
)

# ✅ 安全: 固定マスタ（レース前に確定している値）
df['distance_m']  # レース条件
df['horse_weight']  # 馬体重（発表時点で確定）
df['age']  # 年齢

# ❌ 危険: 全期間集計
df['jockey_win_rate'] = df.groupby('jockey_id')['is_win'].mean()

# ❌ 危険: 当該レースの結果を含む
df['today_jockey_wins'] = ...  # 同日の結果を含む場合
```
