## エグゼクティブサマリー

### 達成した成果

| 券種 | ベースライン | 最適戦略 | 改善幅 |
|------|-------------|---------|--------|
| 単勝 | 86.8% | **113.7%** | +26.9% |
| 馬連 | 86.2% | **184.0%** | +97.8% |

### 発見した最強戦略

```
【単勝】予測1位 AND オッズ10-50倍 → 年平均ROI 113.7%
【馬連】Top1オッズ10-20倍 AND Top2オッズ5-10倍 → 年平均ROI 184.0%
```

### 要注意事項

- 2022年のみ効果が薄い（単勝79%、馬連42%）
- 高ROI戦略はベット機会が少ない（全体の3-17%）
- これらは「購入条件の絞り込み」であり、モデル予測精度の向上ではない

## 現状と発見事項

### 現行モデル（V15）の概要

**モデル仕様**:
- アルゴリズム: LightGBM Binary Classification
- ラベル: `is_win`（1着か否か）
- 特徴量数: 55個
- 実装: `keibaai/src/features/leak_free_feature_engineer_v15.py`

**ハイパーパラメータ**:
```python
params = {
    'objective': 'binary',
    'metric': 'auc',
    'learning_rate': 0.03,

    'max_depth': 3,
    'min_child_samples': 100,
    'reg_alpha': 3.0,
    'reg_lambda': 5.0,
    'bagging_fraction': 0.7,
    'feature_fraction': 0.7,
}
```

## 多角的分析の詳細結果

本セクションでは、2025年1月〜10月のテストデータ（39,325レコード、2,879レース）を対象に
8種類の多角的分析を実施した結果を詳細に記載する。

### 分析1: 予測順位×オッズ帯別の着順傾向

#### 予測1位（Top1）の着順分布

| オッズ帯 | 1着率 | 2着率 | 3着率 | 3着内率 | サンプル数 |
|---------|-------|-------|-------|---------|-----------|
| ~5倍 | 31.2% | 20.0% | 12.8% | 64.0% | 1,637 |
| 5-10倍 | 10.7% | 12.0% | 11.3% | 34.0% | 609 |
| 10-20倍 | 8.6% | 7.6% | 7.9% | 24.1% | 291 |
| 20-50倍 | 6.3% | 5.2% | 6.3% | 17.8% | 191 |
| 50倍+ | 2.0% | 1.3% | 3.3% | 6.6% | 151 |

**解釈**: 
- 低オッズ（~5倍）は1着率31.2%と高いが、配当が低いためROIは伸びない
- オッズ10-20倍帯でも1着率8.6%を維持しており、配当を考慮するとROIが最も高い

#### 予測2位（Top2）の着順分布

| オッズ帯 | 1着率 | 2着率 | 3着率 | 3着内率 | サンプル数 |
|---------|-------|-------|-------|---------|-----------|
| ~5倍 | 29.8% | 19.5% | 12.7% | 62.1% | 1,076 |
| 5-10倍 | 11.4% | 13.6% | 13.4% | 38.4% | 730 |
| 10-20倍 | 5.8% | 8.6% | 9.0% | 23.4% | 431 |
| 20-50倍 | 2.5% | 4.8% | 7.4% | 14.7% | 353 |
| 50倍+ | 0.7% | 1.0% | 2.4% | 4.2% | 289 |

**解釈**:
- 予測2位でもオッズ5-10倍帯では2着率13.6%を維持
- 馬連においてTop2が中穴帯（5-10倍）にいる場合、2着に入る確率が高い

#### 予測3位（Top3）の着順分布

### 分析2: 単勝オッズ帯戦略の4年間堅牢性検証

#### 年別ROI比較（単勝・予測1位購入）

| 年 | ベースライン | オッズ10-50倍 | オッズ20-50倍 | オッズ10-30倍 |
|----|-------------|---------------|---------------|---------------|
| 2025 | 91.8% | **143.1%** (+51.3%) | 197.5% | 112.9% |
| 2024 | 79.4% | **98.1%** (+18.7%) | 122.3% | 96.1% |
| 2023 | 98.2% | **134.4%** (+36.2%) | 130.8% | 133.6% |
| 2022 | 77.9% | 79.4% (+1.5%) | 91.4% | 75.8% |
| **平均** | 86.8% | **113.7%** (+26.9%) | **135.5%** | 104.6% |

**詳細考察**:

1. **2025年（直近）**: オッズ10-50倍戦略でROI 143.1%を達成。2025年はモデルの予測精度が特に高かった年
2. **2024年**: 控えめな改善（+18.7%）だが、オッズ20-50倍帯では122.3%を達成
3. **2023年**: 安定して134.4%を達成。オッズ10-30倍帯でも133.6%と高ROI
4. **2022年**: ほぼ効果なし（+1.5%）。この年は市場効率が高かったか、モデルの適合度が低かった

> [!WARNING]
> **2022年の低調について**
> 2022年のみ戦略効果が薄い原因として考えられる仮説：
> - 訓練データ期間が2021年以前と短い（2020-2021の2年間のみ）
> - 競馬市場の効率性の年次変動
> - COVID-19による無観客開催の影響

### 分析3: 馬連オッズ帯組み合わせ戦略の4年間検証

#### 年別ROI比較（馬連・Top2購入）

| 戦略 | 2025 | 2024 | 2023 | 2022 | **平均** |
|------|------|------|------|------|---------|
| ベースライン | 79% | 85% | 97% | 84% | **86%** |
| Top1 10-50 x Top2 ~10 | 171% | 140% | 162% | 62% | **134%** |
| Top1 10-50 x Top2 5-20 | 143% | 137% | 244% | 103% | **157%** |
| **Top1 10-20 x Top2 5-10** | **232%** | **284%** | **178%** | 42% | **184%** |
| Top1 20-50 x Top2 ~10 | 224% | 90% | 233% | 89% | **159%** |

#### 各戦略の詳細分析

**戦略1: Top1 10-20倍 × Top2 5-10倍（最高ROI: 184%）**

| 年 | ROI | 的中率 | ベット数 |
|----|-----|--------|---------|
| 2025 | 232.4% | 4.3% | 70 |
| 2024 | 284.3% | 5.5% | 91 |
| 2023 | 177.6% | 4.4% | 90 |
| 2022 | 41.9% | 1.0% | 96 |

**解釈**: 
- 2023-2025年は驚異的なROI（177-284%）を達成
- ただし2022年は41.9%と大幅に低調
- ベット数が年間70-96件と少なく、分散が大きい

**戦略2: Top1 10-50 × Top2 5-20（安定性重視: 157%）**

| 年 | ROI | 的中率 | ベット数 |
|----|-----|--------|---------|
| 2025 | 143.2% | 2.3% | 174 |
| 2024 | 137.3% | 2.5% | 237 |
| 2023 | 243.7% | 3.1% | 260 |
| 2022 | 103.4% | 1.4% | 277 |

**解釈**:
- 2022年でも103.4%とプラス収支
- 4年間すべてでROI 100%超え
- ベット数も年間174-277件と比較的多く、安定性が高い

### 分析4: 的中レースと外れレースの特徴比較

予測1位が1着になったレース（的中）と、ならなかったレース（外れ）の特徴を比較

| 指標 | 的中レース | 外れレース | 差分 |
|------|-----------|-----------|------|
| Top1の平均オッズ | 4.3倍 | 16.6倍 | -12.3倍 |
| Top2/Top1オッズ比 | 8.91 | 4.50 | +4.41 |
| レース内標準偏差（オッズ） | 低い傾向 | 高い傾向 | - |

**解釈**:
- **的中時はTop1が低オッズ**（本命馬が予測1位のケース）
- **的中時はオッズ比が高い**（Top1とTop2のオッズ差が大きい＝抜けた1番人気がいる）
- **外れ時は混戦レース**（オッズが拮抗している場合、予測が外れやすい）

### 分析5: 穴馬勝利パターンの分析

オッズ10倍以上の馬が1着になったレース（穴馬勝利）を分析

| 項目 | 値 |
|------|-----|
| 穴馬勝利レース数 | 654レース（22.7%） |
| そのうちモデルTop3予測内 | 125レース（19.1%） |
| 穴馬勝者の平均予測順位 | 5.2位 |
| 穴馬勝者の平均オッズ | 28.4倍 |

## 推奨戦略

### 戦略A: 単勝オッズ帯フィルタリング（推奨）

```python
# 購入条件
def should_bet_tansho(pred_rank, win_odds):
    return pred_rank == 1 and 10 <= win_odds < 50

# 期待ROI: 113.7%（4年平均）
# ベット頻度: 約17%のレース
```

### 戦略B: 馬連オッズ帯組み合わせ（高リスク・高リターン）

```python
# 購入条件
def should_bet_umaren(top1_odds, top2_odds):
    return (10 <= top1_odds < 20) and (5 <= top2_odds < 10)

# 期待ROI: 184%（4年平均）
# ベット頻度: 約3%のレース
# 注意: 2022年はROI 42%と大幅に低下
```

### 両戦略の注意点

> [!CAUTION]
> これらは「モデルの予測精度向上」ではなく「購入条件の絞り込み」。
> 根本的なROI改善には、以下のモデル改修が必要。

### Phase 1: 単勝モデルの本質的改善

#### 1.1 オッズ加重学習の実装

**目的**: 高配当的中を重視した学習

```python
# scripts/training/train_tansho_weighted.py

import lightgbm as lgb
import numpy as np

# 重み計算（オッズが高いほど重視）
train_df['sample_weight'] = np.log1p(train_df['win_odds'])

# 学習
train_ds = lgb.Dataset(
    X_train, 
    y_train,
    weight=train_df['sample_weight']  # ここがポイント
)

params = {
    'objective': 'binary',
    'metric': 'auc',
    'learning_rate': 0.03,
    'max_depth': 3,
    'num_leaves': 20,
    'min_child_samples': 100,
    'reg_alpha': 3.0,
    'reg_lambda': 5.0,
}

model = lgb.train(params, train_ds, num_boost_round=200)
```

> [!WARNING]
> `win_odds`は**sample_weight**としてのみ使用。特徴量としては絶対に使用禁止（リーク）。

#### 1.2 ハイパーパラメータ最適化（ROI基準）

```python
# scripts/training/optuna_roi_tuning.py

import optuna

def objective(trial):
    params = {
        'max_depth': trial.suggest_int('max_depth', 2, 5),
        'num_leaves': trial.suggest_int('num_leaves', 4, 31),
        'min_child_samples': trial.suggest_int('min_child_samples', 50, 300),
        'reg_alpha': trial.suggest_float('reg_alpha', 0.1, 10.0),
        'reg_lambda': trial.suggest_float('reg_lambda', 0.1, 10.0),
    }
    
    model = lgb.train(params, train_ds, num_boost_round=200)
    
    # 評価指標: Test ROI（AUCではない）
    test_preds = model.predict(X_test)
    test_df['pred'] = test_preds
    test_df['pred_rank'] = test_df.groupby('race_id')['pred'].rank(ascending=False)
    
    # Top1購入のROI
    top1 = test_df[test_df['pred_rank'] == 1]
    wins = top1[top1['finish_position'] == 1]
    roi = wins['win_odds'].sum() / len(top1) * 100
    
    return roi

study = optuna.create_study(direction='maximize')
study.optimize(objective, n_trials=100)
```

```python
# 関連度ラベル
def create_relevance(finish_pos):
    if finish_pos == 1: return 5
    elif finish_pos == 2: return 4
    elif finish_pos == 3: return 3
    elif finish_pos <= 5: return 1
    else: return 0

train_df['relevance'] = train_df['finish_position'].apply(create_relevance)
groups = train_df.groupby('race_id').size().values
```

```python
umaren = returns_df[returns_df['bet_type'] == 'umaren'].copy()
umaren['winner_set'] = umaren.apply(
    lambda x: frozenset([int(x['horse_1']), int(x['horse_2'])]),
    axis=1
)
payout_dict = dict(zip(
    zip(umaren['race_id'], umaren['winner_set']),
    umaren['payout']
))

# モデル予測のTop2で購入
top2 = test_df[test_df['pred_rank'] <= 2]
bets = top2.groupby('race_id')['horse_number'].apply(
    lambda x: frozenset(x.astype(int))
).reset_index()

bets['payout'] = bets.apply(
    lambda x: payout_dict.get((x['race_id'], x['horse_number']), 0),
    axis=1
)

roi = bets['payout'].sum() / (len(bets) * 100) * 100
```

## 検証方法

### 必須の検証ステップ

#### 1. 4年間の堅牢性検証

```python
# 年別にTrain/Testを分けて検証
test_periods = [
    ('2025', '2024-12-31', '2025-01-01', '2025-11-01'),
    ('2024', '2023-12-31', '2024-01-01', '2025-01-01'),
    ('2023', '2022-12-31', '2023-01-01', '2024-01-01'),
    ('2022', '2021-12-31', '2022-01-01', '2023-01-01'),
]

results = {}
for year, train_end, test_start, test_end in test_periods:
    train = races[races['race_date'] <= train_end]
    test = races[(races['race_date'] >= test_start) & (races['race_date'] < test_end)]
    
    # 特徴量生成（Trainのみでfit）
    engine = LeakFreeFeatureEngineerV15()
    engine.fit(train, pedigrees, corners, race_details, horses_df=horses)
    
    train_f = engine.transform(train)
    test_f = engine.transform(test)
    
    # モデル学習
    model = lgb.train(params, lgb.Dataset(X_train, y_train), num_boost_round=200)
    
    # ROI計算
    test_f['pred'] = model.predict(X_test)
    test_f['pred_rank'] = test_f.groupby('race_id')['pred'].rank(ascending=False)
    
    top1 = test_f[test_f['pred_rank'] == 1]
    wins = top1[top1['finish_position'] == 1]
    roi = wins['win_odds'].sum() / len(top1) * 100
    
    results[year] = roi
```

#### 2. Train-Test Gap確認

```python
# Train ROIとTest ROIの差を計算
train_roi = calculate_roi(train_df, model)
test_roi = calculate_roi(test_df, model)
gap = (train_roi - test_roi) / test_roi * 100

# 判定基準
if gap < 30:
    print("✅ 健全なモデル")
elif gap < 50:
    print("⚠️ やや過学習気味")
else:
    print("❌ 過学習の疑いあり")
```

#### 3. 年別安定性の確認

```python
# 全年でROI > 100%かを確認
for year, roi in results.items():
    status = "✅" if roi > 100 else "⚠️" if roi > 80 else "❌"
    print(f"{year}: {roi:.1f}% {status}")

# 標準偏差の確認
roi_std = np.std(list(results.values()))
if roi_std < 15:
    print("✅ 安定性良好")
else:
    print("⚠️ 年次変動が大きい")
```
