## 🎯 改善方針概要

### 現状認識（2025-11-24 更新）

**2つのモデル系統を並行開発**:

1. **System A: μv2.0（1着予測）**
   - 現在ROI: **76.72%**
   - 目標ROI: **100%+**
   - 方法: **ベット選択最適化**（EV戦略）

2. **System B: μ/σ/ν（時間予測）**
   - 現在状態: 旧版運用中（ROI 74.50%）
   - 目標: **リーク排除版を新規開発**
   - 方法: 時間予測μモデル + σ・ν再学習

### 基本方針: 並行開発

```
┌─────────────────────────────────────┐
│  System A: μv2.0（1着予測）         │
│  - 優先度: 高                        │
│  - EV戦略で短期ROI向上              │
│  - モデルは変更しない                │
└──────────┬──────────────────────────┘
           │（並行）
┌──────────▼──────────────────────────┐
│  System B: μ/σ/ν（時間予測）       │
│  - 優先度: 中                        │
│  - 中長期の理論的基盤                │
│  - 新規開発が必要                    │
└─────────────────────────────────────┘
```

**理由**:
1. **短期ROI向上**: μv2.0のEV戦略（1週間で実装可能）
2. **長期基盤整備**: μ/σ/νの理論的完成度
3. **リスク分散**: 2つの異なるアプローチ
4. **用途の使い分け**: 単勝 vs 馬連・三連複

### μv2.0モデルからの学び（2025-11-24 追加）

**μv2.0モデル**: μモデルの改良版v2.0（改善継続中）

| 指標 | μv2.0 | μ/σ/ν（μ単体、旧） |
|------|-------|------------------|
| ROI | **76.72%** | 74.50% |
| 的中率 | **25.89%** | 約30% |
| 平均配当 | 2.96倍 | 約2.5倍 |
| データリーク | **完全排除** | νにリークあり |
| 状態 | **改善継続中** | 廃止予定 |

**重要な知見**:
1. **リーク排除の効果**: 8種類のリーク源を排除してもAUC 0.76を達成
2. **血統特徴量**: 世代IDベースの産駒適性が有効（16位、20位にランクイン）
3. **ローリングウィンドウ**: 月次分割で未来情報の完全排除が可能
4. **的中率 vs ROI**: 的中率が高くても人気馬中心だとROIは低い

**μv2.0で排除したリーク源（8種類）**:
1. `final_corner_to_finish` - 最終コーナー→ゴールの順位変動
2. `pace_index` - レースペース指数
3. `passing_order_1-4` - 通過順位（各コーナー）
4. `last_3f_time` - 上がり3F
5. `time_except_last3f` - 上がり以外のタイム
6. `position_change_*` - 位置取り変動
7. `win_probability` - 確定オッズ由来の勝率
8. `finish_time_seconds` - ゴールタイム

**μ/σ/νモデルへの示唆**:
- リーク源徹底排除（特にνモデルの`win_odds`系）
- 血統特徴量の改良（産駒適性ベース）
- `.shift(1)`による過去走集計の厳格化
- ローリングウィンドウ方式の採用

> [!IMPORTANT]
> μv2.0は現時点での最善版ですが、**さらなる改善を継続中**です。承認後、σ・νモデルの改善に進みます。

## 📊 Phase 1: μモデル改善

### 目標

**μモデル単独でROI 70%以上を達成**（現状62.69%から+8%向上）

### 改善施策

#### 1-1. 特徴量エンジニアリング

**追加すべき特徴量**（優先順位順）:

```python
# 1. 過去成績の安定性指標
features['horse_finish_std_last5'] = (
    df.groupby('horse_id')['finish_position'].rolling(5).std()
)
features['horse_finish_cv'] = (  # 変動係数
    features['horse_finish_std_last5'] / features['horse_finish_mean_last5']
)

# 2. 条件変化スコア
features['distance_change'] = abs(df['distance_m'] - df['prev_distance_m'])
features['surface_change'] = (df['track_surface'] != df['prev_track_surface']).astype(int)
features['venue_change'] = (df['venue'] != df['prev_venue']).astype(int)

# 3. 騎手・調教師の組み合わせ
features['jockey_trainer_combo_win_rate'] = (
    df.groupby(['jockey_id', 'trainer_id'])['is_win'].transform('mean')
)

# 4. ペース適性
features['horse_early_speed_index'] = (
    df['passing_order_1'] / df['head_count']  # 早い＝小さい値
)
features['horse_late_speed_index'] = (
    df['last_3f_time'] / df['distance_m']
)

# 5. 休養明けフラグと影響
features['days_since_last_race'] = (df['race_date'] - df['prev_race_date']).dt.days
features['is_休養明け'] = (features['days_since_last_race'] > 90).astype(int)
features['休養明け_win_rate'] = (
    df.groupby(['horse_id', 'is_休養明け'])['is_win'].transform('mean')
)
```

#### 1-2. ハイパーパラメータ最適化（Optuna）

```bash
# 既存のOptunaTunerを活用
python scripts/training/train_mu_model.py \
  --config configs/models.yaml \
  --tune \
  --n_trials 100 \
  --timeout 7200
```

**最適化対象パラメータ**:
- `num_leaves`: 2 ~ 256
- `learning_rate`: 0.001 ~ 0.1
- `feature_fraction`: 0.4 ~ 1.0
- `lambda_l1`, `lambda_l2`: 1e-8 ~ 10.0

#### 1-3. アンサンブル学習


**期待効果**: 単一モデル比+3~5% RMSE改善

#### Step 2: σ・νモデル再学習

```bash
# 新しいμ予測を使ってσ・νを学習
python scripts/training/train_sigma_nu_models.py \
  --mu_predictions data/predictions/mu_pred_for_sigma.parquet \
  --output_dir data/models/complete_new
```

**内部処理**:
```python
# σモデル
mu_pred = load_mu_predictions(args.mu_predictions)
residuals = y_true - mu_pred
sigma_target = np.log(np.abs(residuals) + 1e-6)
sigma_model.fit(X, sigma_target)

# νモデル
sigma_pred = sigma_model.predict(X)
z = (y_true - mu_pred) / sigma_pred  # 標準化残差
nu_true = estimate_nu_by_race_mle(z, race_ids)
nu_model.fit(race_features, nu_true)
```

## 📏 評価指標とベンチマーク

### 主要指標

#### 1. ROI（Return on Investment）

```python
ROI = (総回収額 / 総投資額) * 100

目標: 100%超え（利益が出る）
現状: 62.69%
```

#### 2. Hit Rate（的中率）

```python
Hit Rate = 的中レース数 / 総レース数

目標: 20-30%（高すぎると人気馬ばかりで ROI 低下）
現状: 約30%
```

#### 3. Spearman相関（順位相関）

```python
Spearman = 予測順位と実際順位の相関

目標: -0.6以下（負の相関。小さいほど良い予測）
現状: -0.52
```

#### 4. RMSE（完走時間予測誤差）

```python
RMSE = sqrt(mean((y_true - y_pred)^2))

目標: 現状から-5%改善
```
