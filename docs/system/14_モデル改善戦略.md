## 🎯 最新の推奨戦略

### 現状認識（2025-12-29 更新）

**最終推奨モデル: V15 Fixed + V4.4 Residual Ensemble**

| モデル | 4年平均ROI | 特徴 | 判定 |
|:---|:---:|:---|:---:|
| **V15 + V4.4 Residual** | **81.9%** | **既存ベスト。大穴による上振れ力あり。** | ✅ **継続採用** |
| V24 Binary Ensemble | 79.9% | V15(0.7)+V22(0.3)。安定だが爆発力不足。 | ⚠️ 保険として保持 |
| V23 Hybrid Model | 77.1% | V22 Binary + V15 Residual。シナジー不足。 | ❌ 廃止 |
| V22 Binary (Leak Fix) | 81.3% | 夏場・苦手場に強いが、全体ROIでEnsembleに劣る。 | ℹ️ 特徴量として優秀 |

### 戦略方針

1.  **V15+V4.4 Ensemble を継続使用する**
    - 理由: 4年平均ROIが最も高く、市場の歪み（過小評価された大穴）を捉える能力が唯一あるため。
2.  **V24 Binary Ensemble は「保険」とする**
    - V15+V4.4 のROIが80%を恒常的に下回った場合のみ切り替えを検討。
3.  **V22特徴量はモデル改善の資産とする**
    - 季節・競馬場特化の特徴量は有効性が確認されたため、将来のモデル統合時に活用。

## 🔍 なぜV24 (Binary Ensemble) は失敗したか

**「多様性の欠如」が原因です。**

V15とV22は、設計思想（季節・場所特徴量の有無）は異なりますが、**狙う馬の質（堅実な中穴）が非常に似通っていました**。
- 相関係数: **0.976**（極めて高い）
- 的中率: V15(20.6%) ≒ V22(21.1%)
- 平均オッズ: V15(3.8倍) ≒ V22(3.7倍)

似た者同士を足し合わせても、リスク分散（安定化）にはなりますが、ROIの上限を突破するような化学反応（爆発力）は生まれませんでした。

## 💎 Residual Modelの「宝くじ効果」

一方、V4.4 Residualは**全く異なる性質**を持っています。

| 指標 | V15 Binary | V4.4 Residual |
|:---|:---:|:---:|
| 狙い | 勝ちやすい馬 | **過小評価された馬** |
| 的中率 | 20.6% | **3.9%** (極低) |
| 平均オッズ | 3.8倍 | **17.9倍** (超高) |

Residualモデルは単体では的中率が低すぎて不安定ですが、アンサンブルに組み込むことで**「通常のレースはV15で拾い、稀に来る大穴をV4.4で拾う」**という補完関係が成立しています。
これこそが、V15+V4.4 Ensembleが高ROIを維持し続けている真の理由です。

## 🎯 改善方針概要

### 現状認識（2025-12-24 更新）

**最終推奨モデル**: V15 + V4.4 Residual Ensemble

| モデル | ROI | Gap | σ | 評価 |
|--------|-----|-----|-----|------|
| V15 Fixed | 82.8% | 25.5% | 3.7% | 安定のベースライン |
| V4.4 Residual | 82.6% | 31.8% | 2.2% | 最も安定 |
| **Ensemble** | **83.9%** | **26.9%** | 3.4% | **推奨** |

> [!NOTE]
> V4.4オリジナルの過学習問題（Gap 64.7%）は、**残差学習（Residual Learning）**によって完全解決しました。

**2025-12-24 検証済み改修案**:

| 改修案 | 内容 | ROI変化 | Gap変化 | 結論 |
|--------|------|---------|---------|------|
| V16.2軽度正則化 | num_leaves:18, min_child:110 | **-0.3%** | -1% | ❌ 効果なし |
| データ品質 | Winsorize 3σ | 0% | 0% | ❌ 効果なし |
| 欠損補完 | median/mode | -0.5% | -1.5% | ❌ ROI悪化 |
| 時系列特徴量 | career_count, distance_change等 | -0.3% | **-3.5%** | △ Gap改善のみ |

> **教訓**: V15は既に十分に最適化されており、パラメータ微調整による改善余地は小さい。次の改善は特徴量設計の抜本的見直しが必要。

**2025-12-26 μモデル汎用化検証**:

| アプローチ | 手法 | ROI変化 | 結論 |
|-----------|------|---------|------|
| μ特徴量統合 | μ予測をV15入力に追加 | **-1.3%** | ❌ 効果なし |
| μモデル改善(V5) | 季節性+Huber損失 | 2022:-2.4%, 2023:-3.4% | ❌ ROI悪化 |

> **教訓**: Spearman相関が改善しても（0.32→0.35+）、それがROIに直結するとは限らない。μモデルの単純な特徴量統合は効果がなく、「乖離フィルタ」（V15とμの一致時のみ購入）等のルールベース活用を検討中。

### 基本方針: 並行開発

```
┌─────────────────────────────────────┐
│  System A: μv2.0（1着予測）         │
│  - 優先度: 高                        │
│  - EV戦略で短期ROI向上              │
│  - モデルは変更しない                │
└──────────┬──────────────────────────┘
           │（並行）
┌──────────▼──────────────────────────┐
│  System B: μ/σ/ν（時間予測）       │
│  - 優先度: 中                        │
│  - 中長期の理論的基盤                │
│  - 新規開発が必要                    │
└─────────────────────────────────────┘
```

**理由**:
1. **短期ROI向上**: μv2.0のEV戦略（1週間で実装可能）
2. **長期基盤整備**: μ/σ/νの理論的完成度
3. **リスク分散**: 2つの異なるアプローチ
4. **用途の使い分け**: 単勝 vs 馬連・三連複

### μv2.0モデルからの学び（2025-11-24 追加）

**μv2.0モデル**: μモデルの改良版v2.0（改善継続中）

| 指標 | μv2.0 | μ/σ/ν（μ単体、旧） |
|------|-------|------------------|
| ROI | **76.72%** | 74.50% |
| 的中率 | **25.89%** | 約30% |
| 平均配当 | 2.96倍 | 約2.5倍 |
| データリーク | **完全排除** | νにリークあり |
| 状態 | **改善継続中** | 廃止予定 |

**重要な知見**:
1. **リーク排除の効果**: 8種類のリーク源を排除してもAUC 0.76を達成
2. **血統特徴量**: 世代IDベースの産駒適性が有効（16位、20位にランクイン）
3. **ローリングウィンドウ**: 月次分割で未来情報の完全排除が可能
4. **的中率 vs ROI**: 的中率が高くても人気馬中心だとROIは低い

**μv2.0で排除したリーク源（8種類）**:
1. `final_corner_to_finish` - 最終コーナー→ゴールの順位変動
2. `pace_index` - レースペース指数
3. `passing_order_1-4` - 通過順位（各コーナー）
4. `last_3f_time` - 上がり3F
5. `time_except_last3f` - 上がり以外のタイム
6. `position_change_*` - 位置取り変動
7. `win_probability` - 確定オッズ由来の勝率
8. `finish_time_seconds` - ゴールタイム

**μ/σ/νモデルへの示唆**:
- リーク源徹底排除（特にνモデルの`win_odds`系）
- 血統特徴量の改良（産駒適性ベース）
- `.shift(1)`による過去走集計の厳格化
- ローリングウィンドウ方式の採用

> [!IMPORTANT]
> μv2.0は現時点での最善版ですが、**さらなる改善を継続中**です。承認後、σ・νモデルの改善に進みます。

## 📊 Phase 1: μモデル改善 (ROI Maximization)

### 目標

**購入数を減らさずに、モデルの学習方法を変えることでROI 80%以上を目指す**

### 改善施策

#### 1-1. ROI主導型ハイパーパラメータ最適化

Optunaの評価関数を `AUC` から `ROI` に変更します。

```python
# objective function
def objective(trial):
    # ... params ...
    model = lgb.train(params, ...)
    
    # 予測
    preds = model.predict(valid_data)
    
    # ROI計算 (Top1)
    roi = calculate_roi_top1(valid_df, preds)
    return roi  # Maximize ROI
```

#### 1-2. オッズ加重学習 (Odds-Weighted Training)

学習データに重みを付け、高配当の的中を重視させます。

```python
train_df['weight'] = np.log1p(train_df['win_odds'])
lgb_train = lgb.Dataset(..., weight=train_df['weight'])
```

詳細は [`docs/reports/roi_maximization_strategy.md`](../reports/roi_maximization_strategy.md) を参照。

#### Step 2: σ・νモデル再学習

```bash
# 新しいμ予測を使ってσ・νを学習
python scripts/training/train_sigma_nu_models.py \
  --mu_predictions data/predictions/mu_pred_for_sigma.parquet \
  --output_dir data/models/complete_new
```

**内部処理**:
```python
# σモデル
mu_pred = load_mu_predictions(args.mu_predictions)
residuals = y_true - mu_pred
sigma_target = np.log(np.abs(residuals) + 1e-6)
sigma_model.fit(X, sigma_target)

# νモデル
sigma_pred = sigma_model.predict(X)
z = (y_true - mu_pred) / sigma_pred  # 標準化残差
nu_true = estimate_nu_by_race_mle(z, race_ids)
nu_model.fit(race_features, nu_true)
```

## 📏 評価指標とベンチマーク

### 主要指標

#### 1. ROI（Return on Investment）

```python
ROI = (総回収額 / 総投資額) * 100

目標: 100%超え（利益が出る）
現状: 62.69%
```

#### 2. Hit Rate（的中率）

```python
Hit Rate = 的中レース数 / 総レース数

目標: 20-30%（高すぎると人気馬ばかりで ROI 低下）
現状: 約30%
```

#### 3. Spearman相関（順位相関）

```python
Spearman = 予測順位と実際順位の相関

目標: -0.6以下（負の相関。小さいほど良い予測）
現状: -0.52
```

#### 4. RMSE（完走時間予測誤差）

```python
RMSE = sqrt(mean((y_true - y_pred)^2))

目標: 現状から-5%改善
```
