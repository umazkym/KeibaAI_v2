# 競走馬の強さ比較・分析手法の提案

ユーザー様より頂いた「統一条件+同一時期でのタイム対戦表」をはじめ、各馬の過去成績から強さを多角的に比較・分析するためのアイデアを提案します。

## 1. 同条件・同時期 タイム対戦表 (Time Matchup Table)
**ユーザー提案の具体化**

*   **概要**: 今回の出走馬のうち、過去に「同じ開催（場所・回・日）」「同じ距離」「同じ馬場」で走った経験がある馬同士を抽出し、その時の走破タイムや上がり3Fを直接比較する表です。
*   **メリット**: 指数計算による補正（馬場差など）が入らない「生データ」での比較になるため、納得感が高く、直接的な実力差（その時の調子含む）を感じ取れます。
*   **実装イメージ**:
    *   過去走データをスキャンし、`(場所, 距離, 馬場, 開催回)` が一致するレースをグループ化。
    *   そのグループに今回の出走馬が2頭以上含まれていれば、そのレース結果（着順、タイム、着差）を並べて表示。
    *   例：「2024/10/20 東京 芝2000m」にA馬とB馬が出走 → A馬(1:58.5, 1着) vs B馬(1:59.0, 3着)

## 2. クラス別・基準偏差値 (Class-Relative Performance)
**「格」を考慮した強さの可視化**

*   **概要**: 単純なタイム指数ではなく、「そのレースのクラス（未勝利、1勝C、G1など）」の平均タイムと比較して、どれだけ優秀だったかを偏差値化します。
*   **メリット**: 下級条件で圧勝してきた馬と、上級条件で善戦してきた馬の比較がしやすくなります。「1勝クラスでは抜けて強いが、2勝クラスでは通用しない」といった壁が見えやすくなります。
*   **実装イメージ**:
    *   `races.parquet` からクラスごとの平均タイム・標準偏差を算出。
    *   各馬の過去走について、そのクラス内での偏差値を計算し、直近5走の平均を表示。

## 3. ペース適性マトリクス (Pace Suitability Matrix)
**展開による有利不利の分析**

*   **概要**: 縦軸に「走破タイム指数」、横軸に「レースの前半3F（ペース）」をとった散布図です。
*   **メリット**: 「スローペースの時だけ好走する馬」や「ハイペースの消耗戦に強い馬」が一目で分かります。今回のレース展開予想と組み合わせることで、展開利が見込める馬を発見できます。
*   **実装イメージ**:
    *   過去走の「前半3F」と「タイム指数」をプロット。
    *   今回のレースがハイペース予想なら、右側（ハイペース側）にプロットが集まっている馬を評価。

## 4. 上がり3F「質」分析 (True Closing Speed)
**見かけの数字に騙されない末脚の評価**

*   **概要**: 単に「上がり33秒台」といった数字を見るのではなく、「レース全体の上がり3F平均」との差（乖離）を見ます。
*   **メリット**: 全体的に時計が出る高速馬場での33秒台（価値が低い）と、タフな馬場で他馬が止まる中での34秒台（価値が高い）を区別できます。
*   **実装イメージ**:
    *   指標 = `その馬の上がり3F` - `レース参加全馬の上がり3F平均`
    *   この数値がマイナス（平均より速い）であるほど、そのレースにおいて際立った末脚を使っていたことになります。

## 5. 成長曲線グラフ (Growth Curve)
**勢い（Momentum）の可視化**

*   **概要**: 横軸に「日付」、縦軸に「タイム指数」をとり、その馬の指数の推移を折れ線グラフにします。
*   **メリット**: 「右肩上がりで成長中の馬」と「ピークを過ぎて下降線の馬」、「安定しているが上積みがない馬」の区別がつきます。特に若い馬（2歳〜4歳）の評価に有効です。
*   **実装イメージ**:
    *   各馬ごとに時系列で指数をプロット。
    *   回帰直線を引くことで、「上昇トレンド」か「下降トレンド」かを判定。

## 6. 騎手・厩舎シナジー分析 (Jockey/Stable Synergy)
**人馬の相性分析**

*   **概要**: 「今回の騎手」が乗った時の成績と、「別の騎手」が乗った時の成績を比較します。
*   **メリット**: 「この騎手に乗り替わると勝負気配」「手が合わない騎手」といった定性的な情報を定量化できます。
*   **実装イメージ**:
    *   `今回騎手騎乗時の平均指数` vs `全騎乗時の平均指数`
    *   プラス乖離が大きければ「相性良し（勝負）」と判定。

---

**推奨される次のステップ**:
まずは **「1. 同条件・同時期 タイム対戦表」** の実装をお勧めします。これはユーザー様の直感に最も近く、かつ「直接対決」という事実は非常に強力な判断材料になるためです。
Excelの別シート（例：`Matchups`）に、該当する直接対決データをリスト形式で出力するのが良いでしょう。
