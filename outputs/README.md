# outputs/ — 分析・レポート出力

**目的**: モデル分析やデータ分析の出力ファイルを格納するディレクトリ

## サブディレクトリ

| ディレクトリ | 内容 |
|-------------|------|
| `analysis/` | レース分析結果（Excel等） |
| `experiments/` | 実験結果 |
| `reports/` | レポート |
| `logs/` | 出力ログ |

## results/ との違い

- **`outputs/`**: 一回限りの分析・レポート出力（再現性は不要）
- **`results/`**: モデル検証・バックテスト結果（再現性が重要、バージョン管理対象）
